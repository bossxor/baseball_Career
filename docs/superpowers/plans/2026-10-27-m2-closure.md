# M2 closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Independent domain work uses superpowers:dispatching-parallel-agents. Steps use checkbox syntax.

**Goal:** 미국 연말 계약/연도 이월, 실제 근거 도전 원장, 첫 학교 플레이의 실제 UI 연결을 완성하고 M2 전체의 남은 마감 조건을 숨기지 않는다.
**Architecture:** 기존 엔진·DTO·명령 파이프라인 재사용. US 확장 검증은 별도 계약/연도 원장에 두고 학교/KBO 원장과 구 저장은 보존한다. 독립 앱 연결과 도전 구현을 병렬로 진행하며 공용 인터페이스 편집은 부모가 통합한다.
**Tech Stack:** TypeScript, node:test/tsx, React/Vite, Hono/Drizzle, 기존 의존성.
**Spec:** docs/superpowers/specs/2026-10-27-m2-closure-design.md, 기존13/14/23/58/102/120.

## Global Constraints

- USD 최종 연봉800000~40000000; Major 시작 나이≤29 5년,≤32 3년,≤35 2년,그외1년.
- 다년 계약 총보장 재고 예약1회, 이전 계약금·급여/기록 삭제0, 자동 계약/병역 초기화0.
- 목표/도전 기념 외형만, gameplayRewardDelta:0. 공개 잠재력/seed/RNG 노출0.
- 기존 원장1~3/목표 없는 저장/UI 셸 보존. DD 미추적 증거를 임의 stage하지 않는다.
- 시각 기준은 기존 애니 야구/폰트/CSS 재사용. 새 페이지/자산/의존성 없음.

## Review Focus

- 예산/조건 변조와 중복 수락은 부분 지급/이중 보장 예약 없이 거부한다.
- 옵션/부상/이전 USD/구종/성장은 연말 변경과 첫 새해 경기에도 보존한다.
- 실제 근거 없는 국제/포스팅/복귀 확인은 보상을 해금하지 않는다.
- 기존 셸 저장과 새로운 실제 저장을 섞거나 가짜 기록을 공개하지 않는다.
- 공개 DTO·오류·브라우저 상태가 숨김 원장/잠재력/난수를 노출하지 않는다.
