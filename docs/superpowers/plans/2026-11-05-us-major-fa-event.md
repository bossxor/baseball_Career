# 미국 Major FA E66 사건 연결

기존 실제 FA 자격/현재 견적/원구단+최대3구단/기간/연봉/자금 owner를 유지한다. E66 계약 창의 저장·이동·실제 수락/은퇴 해소만 연결한다. 새 난수/확률/가격/기한/오퍼 재평가 정책을 추가하지 않는다. 기존 Major preview는 현재 owner로 견적을 내며 기존 서명 archive.faOffer가 실제 수락을 보존한다.

- [x] RED: 자격 있는 closed-US root에서 E66 생성/이동/서명해소 미지원.
- [x] optional native 계약창/root guard와 공개 view. NAV는 pending 유지, 실제 서명 시 같은 트랜잭션에서 E66 DOMAIN 완료. 다른 blocking event를 우회하지 않는다.
- [x] 기존 은퇴 요청·취소는 창을 보존하고 실제 은퇴 확정에서만 닫는다(KBO E30/E36 관례). legacy 창 없는 FA 서명은 호환 유지.
- [x] 기존 저장 US play API에 OPEN/RESOLVE와 공개창 연결. funding/world/계약 주입 거부.
- [x] 실제 native FA owner/은퇴/HTTP·JSON/중복/다른사건/부족예산 회귀와 static/build·독립 리뷰 후 문서/증거/커밋.

실행 중2년 복무 회귀는 이미 로드된5f6a1ca+기존WIP 기준으로 제한한다. 이후 추가한 engine 기능은 별도 집중 검사 대상이며 그 실행 종료 시 source 변경 목록을 숨기지 않는다. 전체 통합 증거와 구분한다. PC 종료 금지.
