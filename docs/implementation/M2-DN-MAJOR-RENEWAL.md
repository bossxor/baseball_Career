## 이번 묶음

- 상무 복무 중 시즌 목표는 원구단 대신 SANGMU/FUTURES를 봉인한다. 현역 복무 중 경기 목표 신규 선택/교체는 열지 않는다. 복무 완료 뒤 현재 등록으로 복귀한다.
- FA 전 MLB 보유기간은 사용자 확정대로 매년1년 자동 재계약한다. 기존 가치 산식에 실제 MLB 정규 성적을 반영하고 최종 연봉800000~40000000달러를 보장한다. 숨은 잠재력으로 가격을 매기지 않는다. 공개 계약 기간 helper는 시작 나이별5/3/2/1년이며 실제 FA/포스팅 제안 명령은 후속이다.
- startNextUsMajorSeason은 완료된 정규/PS/성장·필수 선택·병역 기한·FA 여부를 확인하고 다음 해 선수단/계약/재정/급여 기준을 한 번에 반환한다. 신뢰할 서버의30구단 연간 재정 입력만 받으며 UI 금액 입력이 아니다. 원본 저장을 바꾸지 않고 실패하면 기존 저장을 그대로 유지한다.
- 기존 루트1~3 읽기는 유지하고 검증된 메이저 연도 이월만 루트4를 쓴다. 과거 연봉 산정 성적 스냅샷을 보관해 이후 기록 정정이 이미 체결한 계약을 다시 가격 매기지 않게 한다. 급여 원장은 현재 계약 키와 금액을 쓰며 기존 마이너/첫 콜업의 혼합 일할 지급을 보존한다. 계약금은 최초1회, 옵션·서비스·보호명단·원시 기록을 이월한다. 재승격은 기존 메이저 계약을 최저 연봉으로 다시 만들거나 예산을 다시 차감하지 않는다.
- 과거 메이저 시즌 목표의 포스트시즌 자격은 majorYears에서도 조회한다. 첫 캠프 소식을 연간 재계약마다 재생성하지 않는다.
