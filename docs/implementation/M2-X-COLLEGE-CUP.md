# M2-X — 대학 순위·선수권

2026-10-21. M2-W의 대학 정규리그에서 상위4팀 대진을 확정하고 실제 선수권 경기·중단 재개·일마감·우승 결과까지 연결했다. 대학 학년 결과/성장 정산·진급은 다음 단계다.

## 계약과 구현

- `leagueStandings`는01의 승률(무승부 제외)→동률 팀 간 상대승률→전체 득실차→시즌 seed 추첨 순서를 구현한다. 다자 동률은 해당 동률 묶음의 미니리그를 사용한다. 승패0은 승률 미정이며 확정 승률 뒤에 두는 구현 기본안D다. 추첨은 world/season/league/phase 논리 키에 고정된 별도 스트림으로 정하므로 조회/입력 순서가 진행 RNG나 순위를 바꾸지 않는다.
- `startCollegeCup`은 대학 ENROLLED/revision·정규216경기/팀48·연속 일마감 영수증·열린 사건/연말 마감 여부를 검증한다. 정규 일정/기록 근거와 상위4 seed를 고정하고 `POSTSEASON_PROGRESS`로 이동한다. 주인공 팀이 탈락해도 세계 전체 선수권은 진행한다.
- 43의1vs4/2vs3 준결승 단판, 결승3전2선승을 구현했다. 날짜는7월1일 준결승,7월3/5/7일 결승, 상위 seed 홈-하위 홈-상위 홈의 기본안D다. 국제창과 겹치지 않는다. 미정인 실제 날짜/홈 배치를 채운 구현 기본값이며 사용자 수치 승인U로 올리지 않는다.
- 대진은 고정 seed와 공식 FINAL 기록에서 재구성한다. 준결승 이변도 결승의 원래 상위 seed 홈을 유지하고,2연승이면3차전을 생성하지 않는다. 무승부/틀린 팀·날짜·scope·추가 경기·변조된 정규 근거나 우승자를 거절한다.
- `advanceCollegeCup`은 PA1000/완료이닝20 한도의 저장 가능한 worker다. 같은 날 준결승2경기를 모두 게시한 뒤 피로/부상·특성을 마감한다. 경기 준비/게시/일마감은 학교 공통 reducer를 재사용하며 `ScheduledGame.phase=POSTSEASON`만 선수권 일정에 부여한다. 정규 세계 schedule216개는 변경하지 않는다.
- 경기는 실제 POSTSEASON 코어(10회부터 승부치기/20이닝 청크)를 사용한다. `COLLEGE/POSTSEASON` 기록·실전 구종XP·임시 충원/회복·후속 기용을 연결한다. 특성은 정규 출장0인 선수도 현재 선수권 기록으로 평가하며, 정규 PA/outs 조건은 계속 REGULAR만 사용한다.
- 우승 확정 후 SEASON_REVIEW로 돌아오고 cup.status=COMPLETE/우승 팀을 저장한다. 정규48경기 통계/강화 분모와 관측 수를 보존한다. 선수권 참가로 성장 예산이나 학년/나이를 자동 증가시키지 않는다.
