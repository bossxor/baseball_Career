# M2-N 고교 임시 NPC 실제 생성·등록

2026-10-20. 14의 최소 충원 사용자 승인과 M2-K 계획을 실제 고교 세계에 연결했다.

- 건강/등록을 보고 최소 야수9명·필수 우투4명·투수1명을 확보한다. 원선수 복귀 시 필요한 임시 선수만 남기고 초과/부상 임시 선수는 등록 해제한다. 배치가 정상인 경우 생성 RNG를 소모하지 않는다.
- 임시 선수는 기존 고교 NPC 분포(종합35~65·중심48), 유형 배열·잠재력/하드 NPC+5, 독립 손/타석/폼 생성 정책을 재사용한다. 치트 커리어라고 임시 NPC의 잠재력을100으로 바꾸지 않는다. 새 투수는 기존2구종 book으로 시작한다.
- 세계/학교/시즌/단조 증가 serial의 논리 키와 생성·해제 일자를 레지스터에 보존한다. 같은 부족 상태 재처리는 추가 생성/추첨0이다. 잘못된 등록·과거 일자·serial/키 재사용을 거절한다.
- 해제는 roster에서만 제거한다. players/repertoires와 외부 공식 기록 원장의 선수 참조를 삭제하지 않는다. 이후 새로운 부족에는 해제 선수를 재생성하거나 되살리지 않고 새 serial을 사용한다.
- 최초 생성의9팀/225명/25명 검사는 변경하지 않았다. 진행 세계는 기존 부상 선수와 임시 선수 때문에25명을 넘을 수 있다. 초기 생성 검증 함수를 진행 세계에 잘못 호출하지 않는다.

집중4/4·전체173/173, lint/typecheck/build/M1 골든/사건 동기화/설계 정적10종 통과. 전체25명 부상 통제 fixture에서 정확히9H+1P를 충원해 실제 경기를 FINAL 확정하고 기록을 만들었다. 이는 부상 확률로25명이 동시에 다쳤다는 통계 증거가 아니다. 정상 팀 RNG불변·부분 부족 최소1명·JSON 재처리·복귀 등록 해제/신원 보존·새 serial을 확인했다.

미완료: 실제 커리어 phase/진행 명령에서 경기 전 자동 호출, 사건 대기열/도메인 선택·관측/특성/목표·고교 졸업 성장/진로·DB transaction/UI. 반환된 world+registry는 M3에서 함께 저장한다. 다음은19/117에 맞는 커리어 명령·안전 청크/주요 사건 정지를 연결한다.
