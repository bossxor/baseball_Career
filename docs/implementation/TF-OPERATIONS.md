# 야구커리어 TF 운영

2026-11-06 KST 착수. 목표는 기존 설계 기준으로 M2 커리어를 완성하고 화면과 검증을 함께 연결하는 것이다.

| 역할 | 첫 배정 | 담당 경계 |
| --- | --- | --- |
| 00. TF팀장 | SLB 접속 시도, M2 우선순위·통합·검수 | 작업 배정, 승인 경계, Git 통합 |
| 01. 문서관리 | README의 현재 실행·기능 상태 확인 | 설계·결정·진행·테스트·자산 기록 |
| 02. UI·UX 및 에셋 | 시즌을 막는 필수 사건의 화면 연결 공백 조사 | 웹·Android 흐름과 자체 시각 자산 |
| 03. 시뮬레이션 엔진 | KBO P15 증명에 필요한 명령과 공백 조사 | 엔진·저장 상태 호환·경로 증거 |

세 역할 채팅은 기존 야구커리어 프로젝트에 GPT-6.1 Terra로 생성했다. 대화별 작업 경로와 편집 허용 범위를 배정할 때 명시한다. TF팀장 세션 모델 변경은 확인되지 않았다. 단기 작업자는 독립 프로젝트 채팅과 구분한다.

## 기준선

- 확인한 원격 M2 기준은 `0eb9656`. 기존 체크아웃의 미커밋 작업을 보존하기 위해 `E:/AI/Game/baseball_m2_resume`에서 통합한다.
- TypeScript·Node 24, 엔진·규칙, Hono API, Drizzle/PostgreSQL(PGlite 테스트), React/Vite, Android Capacitor.
- 이전 원격 증거는 엔진 전체 경로 4/24다. M2 전체, 장기 병역, 99사건과 PF 검증은 [폐쇄 격차표](M2-CLOSURE-GAPS-20261106.md)와 [최신 인계](NEXT-SESSION.md)를 따른다. 앱 화면의 연결 범위는 [웹 인계](M2-WEB-HANDOVER-20261106.md)를 따른다.
- 앱 목록에서 확인된 기존 야구커리어 채팅은 현 팀장 채팅이다. 이전 Git·검사 이력은 인계 문서에서 참조하며, 별도 세션에 귀속시키지 않는다.

## 작업 기록

작업자는 변경 파일, 재현 명령과 결과, 확인 범위, 남은 위험을 보고한다. 팀장이 Git과 검증 결과를 대조하고 [진행](PROGRESS.md) 및 [최신 인계](NEXT-SESSION.md)를 연결한다. 독립 채팅 간 배정과 회신은 프로젝트 채팅과 Git 근거를 사용한다.
