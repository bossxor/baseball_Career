## 범위와 호출

koreaGameCount의 기존 대진 재생을 count+lastStage 반환으로 바꾸어 같은 이력 탐색에서 경계도 얻는다. 기존 replaceNationalSelectionPlayer의 봉인 점수/동일 역할 예비→나머지 후보·withdrawnKeys 규칙을 재사용한다. 기존 점수·선발 추첨·경기키·선수 신원·세계RNG를 바꾸지 않는다. 모든 공석을 순수 selection 값으로 먼저 채우고 경기 준비 성공 때만 새 root에 넣으므로 실패 후 반쪽 명단이 남지 않는다. 새 선수/능력/잠재력 생성 없음.
