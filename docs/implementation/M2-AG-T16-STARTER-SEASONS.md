# M2-AG — T16 연속 선발 시즌 근거와 특성 도감 투영

2026-10-21. [107](../design/107-RIVAL-HIDDEN-TRAIT-EDGE-RULES.md) §7의 T16(꾸준한 에이스) 근거를 실제 공식 기록과 시즌 마감에 연결했다. 새 게임 규칙은 추가하지 않았다.

- `starterSeasonEvidence`: 한 세계 시즌에서 OFFICIAL REGULAR 대회마다 선발 outs 합계가 `3×G` 이상인지 본다. G는 그 대회 시즌의 팀별 공식 경기 수 최댓값이다. 구원 outs와 포스트시즌은 numerator에 넣지 않는다. 충족 대회가 여럿이면 선발 outs/G가 큰 순서→leagueKey 순으로 근거를 정렬한다.
- `settleStarterSeasonTraits`: 정규 시즌 마감(`SEASON_REVIEW` 진입) 때 시즌 키당 한 번만 연속값을 갱신한다. 충족이면 직전 세계 시즌 인덱스가 연속일 때 +1, 아니면 1부터 시작한다. 미충족 시즌은 0으로 끊는다. 같은 시즌 재처리는 변화가 없고, 이미 처리한 시즌보다 이른 시즌은 `STARTER_SEASON_OUT_OF_ORDER`로 거절한다.
- 연속값이 5가 되는 시즌 마감 receipt(seasonKey 포함)에서 T16을 해금한다. 해금 후 미충족 시즌이 와도 보유 특성은 박탈하지 않는다. 일별 특성 평가도 같은 연속값을 근거로 사용한다.
- 고교 1시즌과 대학 4시즌이 연속된 세계 시즌이면 아마추어 경로에서도 5시즌에 도달할 수 있다. 대학 선수권(POSTSEASON)은 근거에 넣지 않는다.

## 특성 도감(S38) 읽기 투영

`careerTraitView`는 [100](../design/100-HIDDEN-TRAITS.md) 확정 규칙대로 내 선수의 특성 화면 데이터를 만든다.

- 일반 특성 6개(선수 종류별)는 이름·효과와 56 조건의 정확한 정수 진척(현재/목표)을 보여 준다. 능력 조건은 영구 능력의 정수 부분으로 비교한다. 보유하면 진척을 비운다.
- 히든 특성 2개는 미해금이면 이름·암시만 내보낸다. 진척·조건·근접도는 응답에 넣지 않는다. 해금 후에만 조건·효과·근거(시즌:날짜)를 공개한다.
- 순수 함수다. 난수·revision·원장을 바꾸지 않고 잠재력·seed를 응답에 넣지 않는다. API/화면 연결은 후속이다.

검증: 집중3개(3×G 경계·포스트시즌 제외, 5연속 1회 해금·재처리0·순서 역행 거절, 공백 시즌 초기화·해금 후 유지)와 기존 특성/고교·대학 진행 경로. 실제 결과: T16·특성·고교216경기·대학 경로 포함 집중28/28(1001.5초), 도감 투영2/2, 타입·lint·build·M1 골든·이벤트 동기화·설계 정적10종 통과. 전체 테스트 묶음(npm run check) 단일 재완주는 하지 않았다.
