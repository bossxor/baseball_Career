# M2-CM — 상무·복귀 성장 기간 분할

## 목적과 범위

21·42의 원래 성장 규칙을 새 상무 입대에 연결한다. 상무에서 뛴 기간과 둘째 시즌6월30일 이후 원구단 등록 기간을 하나의 세계시즌 성장 원장에서 정산한다. 성장 배율·잠재력·연간 예산·강화 횟수는 늘리지 않는다. ACTIVE 경로를 이번 결과로 주장하지 않는다.

새 입대는 growthPolicyVersion1을 저장한다. kboMilitaryGrowthPeriods는 실제 성장 달력과 기존 육성 계획 경계를 사용한다. 첫 복무 시즌은 전체 상무 기간, 둘째 시즌은6월30일 포함 복무 기간과 그다음 날부터 원구단 기간으로 나눈다. 국제창은 성장 달력에서 제외된 그대로이며 복무 날짜를 옮기지 않는다.

상무 기간은 상무의 실제 FUTURES 정규 경기, 복귀 후는 원구단의 실제 리그 등록 영수증에 포함된 경기만 읽는다. 등록 벤치의 팀 경기 수와 개인 타석/아웃을 구분한다. 잘못된 팀 출장·등록 없는 출장·동일 날짜 두 경기·변조된 복무 달력은 거절한다. 부상·회복은 기존 일마감 증거를 읽으며 달력 날짜로 remainingTeamGames를 소모하지 않는다.

육성 계획 변경, 강화 창의 팀 경기 수는 상무 등록과 원구단 등록을 이어서 센다. 팀 이동으로 같은 시즌 강화 기회를 새로 만들지 않는다. 상무도 PRO/Futures의 기존 표준분모(PA500·SP450아웃·RP/CP150아웃)를 사용한다. 기간별 표준분모는 성장 일수에 비례한다. 누적 예산은 공통 naturalGrowthBudgetUnits와 성장 원장의 반올림을 유지한다. 재호출·JSON 복원은 지급0이다.

## 호환과 한계

선택 필드 없는 기존 저장은 읽을 때 버전을 붙이거나 과거 성장 지급을 재계산하지 않는다. 새 입대 또는 명시적인 다음 시즌 활성화에서 아직 경기/성장 기록이 없는 새 시즌에 적용한다. 이미 마친 시즌의 원장과 기존 육성 계획 경계는 보존한다. 미정산인 기존 진행 시즌도 자동 전환하지 않는다. 복귀 뒤 이후 시즌은 평소 PRO 경로로 돌아간다.

현역 성장0·휴식·복귀6경기 효과, NPC상무 성장/반년 복귀, 군팀 부상/긴급 편성은 후속이다. 시즌 중 다른 구단으로 이적하는 계약 경로도 사용자 확정 후 별도 작업이다. 실제 UI·계정·Neon·APK는 아직 없다.

## 검증

성장 집중8/8(새5+기존3), 입대/이벤트5/5 통과 후 새 시즌 적용과 등록 조회 비용을 보강했다. 새 시즌 활성화2/2 재검증·최종 성장8/8 통과. 전체 npm run check501/501·실패0·취소0, lint/타입/build/골든/이벤트/설계10종 통과. duration_ms 1004136.4323. [전체 로그](evidence/M2-CM-check.log).

성장 테스트는 날짜·공식 기여·등록 영수증을 통제한 fixture로 분할/합계/중복/오류/구 저장 보존을 검증한다. 전체18개월 모든 경기를 실행했다고 하지 않는다. 기존 입대·6월30일 날짜 큐 테스트는 실제 엔진 명령을 사용한다.

전체 검사 뒤 끝의 빈 줄만 정리했다. 두 소스의 본문 정규화 해시 일치 증거는 [형식 증거](evidence/M2-CM-format-only-source.json)에 남겼으며 lint 재검증도 통과했다. 기능 코드는 바꾸지 않았다.
