# M2-C 세계 생성·일정

2026-10-20. M2 전체가 아닌 세계 초기 상태/일정 슬라이스.

## 반영

- 사용자확정 고교9학교·학교당25명(야수15/투수10), 팀48/리그216경기. 주인공은 선택 학교의 같은 포지션 슬롯을 대체하며 총225명을 유지한다.
- 사용자확정 NPC 종합35~65·중심48. 삼각분포 최빈48→정수화, 유형 고정배열에 평균 차이 가산. 잠재력은 기존42/85이고 하드가 현재 능력을 몰래 올리지 않는다. 모든 초기 NPC는18세인 첫 고교 코호트이며 이후 학년별 인원/신입 이월은 아직 연결 전이다.
- 세계 생성용 roster/potential/protagonist/handedness 스트림 분리. 70의 논리키만 사용한다. 생성은 CREATED 상태이며 첫 경기/졸업/오퍼를 실행하지 않는다.
- 고교/대학9팀48·216, KBO10팀144·720, MLB30팀162·2430, 마이너30팀60/100/120/144 일정을 생성한다. 6라운드 뒤 쉬고 동일 날짜 중복을 금지한다. 달력 시작일/대회 휴식창은 상위 세계 달력에서 제공해야 한다.
- MLB는 상대29팀×5+서로 다른17상대 추가1. 전체 게임 그래프의 오일러 방향으로 정확 홈81/원정81을 보장한다. 홀수팀은 bye를 넣고 고교/대학 상대당 홈3/원정3, KBO 홈8/원정8이다.
- 생성 불변조건으로 학교별 역할/개수/중복등록·선수키·투수 book을 검사한다. 실패하면 부분 세계를 반환하지 않는다. DB staging/생성receipt 게시의 원자성은 M3에서 따로 검증한다.

## 실제 검사

집중10/10(세계5·일정5), 전체검사104/104 및 lint/typecheck/build/기존M1골든/정적설계10종 통과. 생성 동일 seed/직렬화 재개/다른 seed, 모든 유형, 하드·치트 RNG 보존, 잘못된 명단과 손상 거절을 확인했다. 원격CI 결과는 별도 미확인.

## 이어서

고교 CREATED→프리시즌→실제 시즌/이벤트/결산을 이어야 한다. initial world는 읽기 내부 상태이며 공개 DTO가 아니다. seed/진짜P를 API에 반환하면 안 된다. 학교 명칭은 가상 작업명이며 실제학교 연계가 없다. 프로 전체 로스터, 대학 학년 명단, 세계 달력의 대표팀 휴식창 및 연도 rollover는 아직 구현 전. 초기계약/계정/DB/화면/APK도 이 슬라이스의 증거가 아니다.
