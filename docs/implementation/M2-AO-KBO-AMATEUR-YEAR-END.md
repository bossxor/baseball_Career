# M2-AO — KBO 계약 후 학교 연말 마감

2026-10-21. M2-AC의 계약·다음 시즌 자리/연봉 예약에 이어 명시적인 학교 연말 마감을 연결한다. 프로 실제 활성화/일정/경기는 아직 연결하지 않았다.

## 구현

closeSchoolSeasonForKbo는 서명한 실제 계약·졸업 진로·프로그램 원본을 검증하고 미사용 강화를 명시적으로 포기한 뒤 연간 성장/건강을 닫는다. 구종 학습 미정산, 낡은 버전/변경된 증거는 거절한다. 성장/나이/급여를 추가 지급하거나 프로1군을 보장하지 않는다.

새 kboYearEnd는 계약/서명 영수증과 원래 모집 근거를 연결하고 전체 커리어 상태를 봉인한다. 모집/계약 스냅샷과 기초500명 세계는 그대로 보존하며 유효한 봉인 경로에서만 마감 후 계약 조회를 허용한다. 없는 저장값은 기존 동작을 유지한다. 같은 학교 연말의 반복 마감은 거절하며 같은 원본 재실행/JSON 복원은 같은 결과다.

E94 읽음은 마감 봉인을 먼저 확인하고 읽음 메타데이터에 맞춰 같은 영수증의 revision/봉인만 갱신한다. 변조된 봉인은 복구하지 않는다. 경미/중간 부상의 남은 팀경기는 달력 휴식으로 줄이지 않고, 시즌 중대 부상만 기존 건강 규칙으로 닫는다. 프로 활성화는 이 봉인을 검증해 보관/나이1회/새 예산/기존 signing의 자리·급여1회 반영을 처리해야 한다.

## 검증

타입·lint·전체 build·compiled M1 골든·이벤트 동기화·설계 정적10종·HTTP smoke 통과. 첫 관련26개 중25개 통과,1개는 경미 부상 fixture에 유효 상한7을 넘는8경기를 넣어 INVALID_INJURY_DURATION으로 거절됐다. 경미3/중간8로 테스트만 수정한 뒤 연말 전용6/6(11.39초)을 통과했다. 제품 건강 검증을 완화하지 않았다. 연말 뒤 일반 특성 요약 읽음도 두 연말 봉인의 revision/근거를 검증·갱신하도록 고쳤다. 이 수정으로 첫 전체 실행은 중단했고 로그를 full-check-interrupted로 보존했다. 실제 대학 등록까지 이어지는 별도 회귀1/1(9.05초), KBO 봉인 뒤 일반 특성 요약 회귀1/1(2.64초), 최종 테스트 파일을 포함한 타입 검사도 통과했다. 최종 전체 npm run check가337/337(1131.07초)·실패0으로 종료했다. 실제 고교216경기와 실제 대학216경기/선수권, 전체 lint·소스/테스트 타입·build·compiled M1 골든·이벤트 동기화·설계 정적10종을 포함한다. 최종 HTTP smoke도 통과했다.

## 후속 실제 프로 활성화 인계

1. assertCareerKboSigning과 assertKboAmateurYearEnd를 모두 검증한 원본만 사용한다. 서명 예약/학교 연말 마감/프로 실제 등록은 각각 별도 영수증이다.
2. 현재 학교 세계는 archiveSchoolSeason의 실제 연말 영수증으로 보관하고 누적 HS/COLLEGE 기록을 KBO 기록에 합산하지 않는다. 기존 relations/trait/book/P/최고값/권리 이력은 보존한다.
3. kboRecruitment.world는 이미 다음 연도용500명 세계다. NPC500명을 다시 생성하거나 모두 한 살 더 먹이지 않는다. 내 선수만 학교 나이+1·피로0으로 옮기고 새 시즌 성장/구종 XP 예산을 연다. 기존 배운 book/weights는 유지하며 학습 미정산 상태는 앞 단계에서 거절한다.
4. signing.rosterAfter와 reservedSalaryAfterWon을1회 실제 대상 구단에 반영한다. 기초90억원에 새 최저3천만원을 더한 예약과51명 로스터를 사용하며 두 번 더하지 않는다. firstTeam:false를 지키고 등록만으로1군/경기 출장을 보장하지 않는다.
5. 계약·로스터·연봉·권리·활성 등록·새 동료 형성을 단일 순수 전환 결과로 만든다. E94는 실제 프로 등록이 확정된 뒤 생성한다. 기존 학교 명령이 프로 세계를 HS로 오인하게 leagueKey만 넓히지 않는다. KBO/퓨처스 달력·선수단/라인업·정규/PS 진행은 실제 프로 모델을 도입할 때 연결한다.
6. 원본 불변/JSON 재개/같은 원본 결정론·중복 입력 거절, 나이/연봉/성장1회, 과거 신원 조회·부상 이월·원래 모집 원장 보존을 검사한다. 실제 프로 API/저장·화면이 없는 상태에서 계정 이어하기/프로 경기 구현 완료라고 보고하지 않는다.

## 배포·롤백 경계

kboYearEnd가 없는 기존 저장값은 기존 모집 원본 검사 경로를 유지한다. 새 봉인 저장값을 되돌릴 때는 마감 writer만 중단하고 새 봉인 reader/메타데이터 읽음 처리는 유지한다. kboYearEnd를 지우거나 모집 sourceBasis를 덮어써서 옛 코드에 맞추지 않는다. 이미 기록한 강화 포기·건강 마감·성장 최종화도 제거하지 않는다. 실제 DB 스키마/마이그레이션은 이번 단계에 없다.

작업 원본 V:/와 Git 체크아웃의 이번 코드·테스트10개는 SHA256 비교 차이0이다. 증거는 evidence/M2-AO-source-sync.json이다.
