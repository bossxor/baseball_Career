# M2-CD — 상무 부대의 커리어 연결 (선발 명령·11팀 일정·경기 진행·연도 전환)

2026-10-22. M2-CA~CC의 순수 부분을 프로 커리어 흐름에 옵트인으로 연결했다. 부대가 없는 기존 커리어(`career.sangmu` 없음)는 동작이 같다.

- **명령 `startSangmuCohort`**(PRESEASON_SETUP, 개막 명단·일정 확정 전, 시즌당 1회): 선발 시즌 = 직전 시즌으로 야수10·투수10을 뽑아 `career.sangmu`(KboSangmuUnit)에 입대시킨다(첫 블록 = 올 시즌 전체). 내 선수는 대상 아님. 1군이 줄어든 AI 구단은 41/44 선택기로 28명을 다시 고르고 내 구단은 이후 개막 명단 확정이 고른다.
- **선발 조정(구현 기본값 D)**: 이 연결을 하다가 드러난 제약으로 선발 규칙을 보강했다. ① 8개 수비 포지션마다 최고 지원자를 먼저(야수), 투수는 선발 3명 이상 ② **구단당 야수 1명·투수 2명 상한**(퓨처스 야수가 11명뿐이라 9명 미만이면 합법 라인업이 불가능). 사용자가 정할 10명 역할 배분 세부는 여전히 후속이다.
- **11팀 일정**: 복무자가 있으면 `confirmKboSeasonSchedule`이 FUTURES를 `createKboFutures11Schedule`(상무 포함 792경기)로 만든다. 1군은 기존 720경기. 부대가 없으면 기존 10팀. 일정 조회는 상무 이름을 '상무'로 표시.
- **경기 진행**: `advanceKboCareer`/포스트시즌/일마감이 부대를 투영·일마감에 넘긴다. 상무 선수의 피로·휴식은 부대 안에서 갱신되고, 투수 구종 숙련은 부대원 책에 병합된다(세계 구종 원장에 없음).
- **부상(ponytail)**: 상무에는 아직 부상/긴급 등록 모형이 없다(야수 10명은 부상 2명도 못 버틴다). 상무 팀 경기는 건강 원장을 정산하지 않는다. 피로는 적용된다.
- **연도 전환**: 부대원은 나이+1·피로0·구종 연간 초기화를 받고, 이번 시즌에 해당하는 복무 블록이 시즌 마지막 날로 완료 기록된다. 두 블록이 끝난 선수는 원구단 퓨처스로 복귀(정원 60이면 부대 대기, 계약일이 없으면 무계약 보고). **한계(ponytail)**: 둘째 블록(다음 시즌 전반)은 시즌 말에 닫혀 실제로는 두 시즌 복무다. 반년 시점 복귀(시즌 중 이적)는 미구현. 복무 중 성장·노쇠(연간 기본×복무 비율×퓨처스 출장 계수)와 서비스 연차 0 처리는 아직 적용하지 않았다.
