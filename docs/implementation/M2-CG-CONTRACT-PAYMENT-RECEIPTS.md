# M2-CG — 정지 계약의 복귀·일일 지급 영수증 기반

2026-10-22. 작업 시작 HEAD/origin main 6d69535. Git 추적1,073개 파일과 V: 원본을 바이트 비교해 차이0을 확인했다. 이번부터 사용자 요청대로 체크아웃에서 수정하고 검증된 변경만 V:에 반영한다. V:/.git 생성/수정 없음.

## 변경

- 기존 CB의 일급·정지 잔액 산식을 재사용한 KboContractPaymentLedger. 정지 상태에서는 지급 명령을 거절하며 잔여일·원금이 줄지 않는다.
- 같은 프로그램·같은 정지 계약·두 블록의 순차 완료 증거가 있어야 재개한다. 다른 원금/프로그램/복귀 증거는 거절한다.
- 공식 정규 KBO/FUTURES 경기와 해당 팀 등록 건강 영수증을 결합해 실제 등록1경기당1일 지급한다. 출전하지 않은 벤치/부상 등록은 지급 대상이다. PS/국제경기·미등록·상무 소속·복귀 이전 날짜는 대상이 아니다. 원구단으로 돌아온 선수가 상무를 상대하는 정상 퓨처스 경기는 지급 가능하다.
- 경기 키와 등록 근거를 저장한다. 재호출/JSON 재개는 추가 지급0원이며, 변경된 근거·같은 날 다른 경기·역순 신규 지급·계약일 초과는 거절한다. 반환 영수증은 입력 원장과 객체를 공유하지 않아 반환값 수정으로 과거 상태가 바뀌지 않는다. 마지막 날 반올림 잔여를 정산하고 지급액+잔액=동결 총액을 유지한다.
- 내 선수 상무 ENLIST가 수락한 재계약의 키·기간·연봉을 정지하도록 수정했다. 종전 코드는 재계약으로 잔여일을 계산하면서 옛 계약 키/연봉을 정지해 금액이 불일치했다. 기존 저장 계약/프로그램은 소급 재작성하지 않는다.
