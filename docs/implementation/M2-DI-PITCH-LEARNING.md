# M2-DI 구종 학습 실제 경기 연결

기존 M2 체크아웃에서 직접 구현한다. 별도 구현 초안은 더 이상 사용하지 않는다. origin/main 6eda98e(M8/M9 셸)를 통합하되 M2와 병렬 진행 문서를 모두 보존했다.

## 구현

학교(고교·대학 공통) 사전 구종 학습/배분 명령을 공개하고, 학습 계획에 세계·선수·고정 시즌 경기 수·시작 부상 여부를 봉인했다. 고교/대학·KBO·상무·미국의 실제 FINAL 공식 기록과 건강 등록 영수증으로 분기를 정산한다. 건강한 등록 경기만 XP를 지급하고 같은 분기 재실행은 재지급하지 않는다. 일반/하드 NPC/치트의 기존 배율과 예약 예산·정수 잔여를 유지한다.

건강 원장은 변경하는 부상·RNG만 복사하고 과거 불변 영수증은 공유한다. 미국 다일 청크의 레벨 검토 후 시즌 객체 참조도 유지한다. 새 의존성 없음.
