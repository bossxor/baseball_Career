# M2-CI — 상무 6월 복귀와 E52·E53

2026-10-22. 새로 입대한 내 선수의 상무 복무를 실제 달력 일마감에 연결했다. 사용자 결정은 두 번째 복무 시즌 6월30일 완료이며, 14 U·21에 기록했다.

## 변경

첫 블록은 첫 복무 시즌 정규 일정 마지막 날, 둘째 블록은 다음 시즌 6월30일에 완료한다. 윤년의 날짜도 달력으로 계산한다. 해당 날짜 경기를 모두 마감한 뒤 복무를 완료하고 원구단 퓨처스 자리를 복구한다. 원구단 등록 경기는 다음 날짜부터 가능하며 같은 날짜 양 팀 중복 출전을 막는다. 처리일을 놓친 상태는 임의로 소급하지 않고 오류로 거절한다.

첫 시즌 프리시즌 E52에서 기존 네 가지 성장 집중 능력을 확인하거나 다시 선택한다. 기존 프리시즌 명령을 재사용하므로 별도 성장 보너스는 없다. 실제 복귀일에는 E53이 진행을 멈추고 확인 뒤 남은 시즌을 이어간다. 공개 조회에는 선택지·현재 집중 능력만 제공하며 잠재력·RNG는 노출하지 않는다. 오래된 completionDays 없는 저장은 기존 연말 처리 경로를 유지하며 읽기에서 자동 전환하지 않는다.

## 검증

최종 집중5/5, 타입·lint·설계 정적10종 통과. 전체 npm run check 종료코드0·485/485·실패0·취소0·1321286.8867ms 통과. lint·타입·build·골든·이벤트·설계10종도 통과했다. 최초 집중 실패2건은 테스트 입력에서 능력치 내부 단위를 잘못 사용한 문제였으며, 올바른 ABILITY_MAX_UNITS로 고친 최종 실행과 실패 로그를 모두 보존한다.

집중 테스트는 이전 기간을 통제된 달력 영수증으로 구성하고 실제 포스트시즌 및 6월30일 이후 경기 작업자를 실행한다. 18개월 모든 경기를 처음부터 시뮬레이션한 검증으로 주장하지 않는다. 집중 최종 로그: [M2-CI-focused-final.log](evidence/M2-CI-focused-final.log). 전체 로그: [M2-CI-check.log](evidence/M2-CI-check.log).
