# M2-AP — KBO 신인 실제 선수단 등록

2026-10-21. M2-AO의 서명/연말 봉인을 검증한 뒤 startSignedKboCareer가 새 KboCareer를 만든다. 학교 루트를 프로 루트로 바꾸는 순수 전환이며 DB 쓰기는 아직 없다.

## 연결한 동작

- 기존 next-season KBO500명 세계를 그대로 사용한다. 내 선수만 나이+1·피로0으로 등록하고 대상 구단의 rosterAfter51명·reservedSalaryAfterWon을1회 반영한다. 다른 구단과 NPC500명의 나이/능력/P/계약·기존1군28명은 바꾸지 않는다. 계약/국내 권리는 signing 원장을 복사하며 계약금/급여를 새로 지급하지 않는다.
- ACTIVE는 구단 선수단 등록이다. registration.firstTeam:false를 유지하며 KBO1군/퓨처스 경기 등록이나 출장을 뜻하지 않는다. phase는 PRESEASON_SETUP이며 일정/경기 명령은 후속이다.
- KboCareer는 별도 프로 루트다. 기존 학교 세계를 HighSchoolWorld의 잘못된 leagueKey로 넓히지 않는다. amateurHistory에 유효한 학교 원본/봉인/관계/구종/졸업·대학 이력을 보관하고 누적 공식 records를 복사한다. 학교 기록을 프로 통산으로 합산하지 않는다.
- 새 시즌 성장/구종 XP 예산을 열고 book/weights·능력/P/최고값·과거 강화 사용/특성·스타일 창을 보존한다. 부상은 내 선수의 남은 팀경기만 이월하고 옛 학교 다른 선수 부상은 archive에 남긴다. 나이·등록만으로 자연성장을 지급하지 않는다.
- 승인된 새 팀 최초 등록 규칙으로 실제 같은 구단 선수단의 동료1명을 추가한다. 고교/대학 관계를 보존하고 E94를 비차단 relationNotices에 추가한다. 기존 형성 알림과 읽음 상태도 유지한다. 관계 writer에 필요한 최소 등록 문맥만 분리해 학교/프로가 공유한다.
- kboCareerEntryView는 이름/나이/포지션·구단·등록·계약/진입 단계만 제공한다. raw KboCareer에는 P/RNG/봉인된 학교 이력이 있으므로 API에 그대로 반환하면 안 된다.

## 원자성·호환

원본은 불변이다. 같은 원본/JSON 복원은 같은 결과이며 출력 프로 루트를 다시 학교 활성화 명령에 넘기면 거절한다. DB/저장 작업자는 activation.sourceRevision과 영수증 키를 확인해 저장된 학교 루트를 한 번만 대체해야 한다. 순수 함수 재실행 검증을 DB transaction/중복 저장 방지 구현이라고 보고하지 않는다. kboRecruitment의 기초500명/원래 예약을 활성세계501명에 다시 합산하지 않는다.

기존 학교 저장값은 바꾸지 않는다. 새 KboCareer는 world.status ACTIVE와 별도 프로 세계/등록/activation 필드로 식별하고 학교 명령에 전달하지 않는다. 롤백 시 진입 writer를 중단하더라도 새 프로 루트 reader와 amateurHistory를 보존해야 하며, 활성 프로 상태를 amateurHistory로 덮어쓰면 안 된다. 실제 저장소의 루트 union/마이그레이션과 계정 저장은 후속이다.
