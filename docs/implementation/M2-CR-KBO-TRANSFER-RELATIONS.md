# M2-CR — 실제 이적의 원구단 관계 분리

2026-10-23. 기존 CQ 이적 수락 안에서 원구단의 실제 등록 관계를 분리한다. 타구단 수락 성공 시 FORMED/REUNITED_TEAM인 RIVAL·TEAMMATE만 SEPARATED로 바꾸고 transferReceipt 기반 milestone을 한 번 추가한다. 기존 type·관계키·이전 모든 milestone·첫 등록 영수증은 보존한다. 새 구단 동료/E94 형성은 기존 CQ 흐름을 그대로 따른다.

원구단 소유 명단에 있어도 군팀 대여/현역 복무로 실제 같은 팀이 아니면 제외한다. 부상 등록은 같은 구단 관계에 포함한다. 이전 학교/대학/상대 구단·이미 분리/상대 재회/은퇴한 관계는 그대로 둔다. 같은 구단 재수락·비교 열람·실패한 이적은 분리하지 않는다.

수정은 전부 기존 이적의 복제본 안에서 이뤄지며 실패하면 관계/권리/돈/세계/RNG 원본 불변이다. 관계 목록은 기존 stage 표시를 사용한다. 공지 읽기는 읽음만 바꾸며 분리 자체가 E95/E96 재회 공지를 만들지 않는다. 같은 원본 및 JSON 복원 재시도 결과는 같고 이미 분리된 이력에 같은 milestone을 추가하지 않는다.

## 저장 호환과 범위

스키마나 의존성을 추가하지 않는다. 기존 KBO v4와 이미 정의된 SEPARATED를 사용한다. 이미 CQ로 이적 완료한 저장은 목록 조회/공지 확인에서 소급 분리하지 않는다. 이전 CQ 형태를 재현한 통제 fixture로 이를 검사하며 배포된 구버전 바이너리 전체를 시험했다고 하지 않는다. 롤백 때 이전 저장과 코드를 함께 보존하고, 이미 기록한 분리 milestone을 임의로 삭제하지 않는다.

다음 E95 상대 양쪽 실제 출장, E96 다시 같은 팀 등록은 미구현이다. 실제 UI/API/DB 저장 및 NPC 병역·미국 실제 리그도 이 범위가 아니다.
