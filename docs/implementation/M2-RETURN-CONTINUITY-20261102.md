2. 귀국 후 미국 재계약의 누락된 연속성을 수정한다. 완료한 귀국 시즌의 실제 기록·건강·성장 자원과 병역 상태를 유지하며, 다음 미국 시즌의 NPC 나이·선수단·재정 연도를 일치시킨다. 진행 중인 귀국 시즌을 버리는 선택은 거절한다. 새 확률·연봉·지원금 규칙을 만들지 않는다.
3. 기존 경로 검증기에 P16 실제 재도전 소진·은퇴 명령을 연결한다. 과거 두 번의 준비/프로 시즌은 제어 fixture, 마지막 독립 48경기와 은퇴 명령만 실제 실행이라는 경계를 유지한다. `--scenarios=retry` 등 선택 실행과 `.json.gz` 증거 출력을 지원한다. P16 명령 전체 JSON 재실행은 약 15분 뒤 중단했다. 실행 로그와 종료 코드를 보존하며, 완료 해시 또는 P16 통과로 표시하지 않는다. 이 별도 재실행 대신 기존 재도전 통합 테스트를 전체 검사에서 실행한다.
4. 변경을 모은 뒤 집중 검사와 전체 check 1회를 수행한다. 검사 명령과 결과를 증거 로그에 남긴다. STATUS/PROGRESS/NEXT/HANDOFF를 갱신하고 승인 범위의 변경만 커밋·푸시한다.

## 확인된 문제

- 재계약 결과가 source 기반 records/health/development를 사용해 실제 독립 경기와 성장 자원을 잃는다.
- 마지막 귀국 시즌 종료에서 NPC 나이를 올리지 않아 세계 연도와 나이가 어긋난다.
- 재계약 inventory가 목표 시즌보다 1년 이전 상태로 남는다.
- 다음 귀국 시즌이 이미 시작돼도 이전 완료 연도의 endingPlayer로 재계약할 수 있다.
- 1년 재계약의 continuation에 기존 6년 보유기간을 저장한다.
- 타 구단으로 재계약한 뒤 다음 갱신의 과거 재무 재생이 최초 미국 구단을 보유 구단으로 사용한다. 새 continuation은 조직 ID를 저장하고 실제 서명 영수증과 비교한다. 기존 ID 없는 저장은 실제 이전 갱신 영수증으로 조직을 복원한다.
- 준비 기간 관계를 복원하면 base에서 생성한 새 동료 관계가 사라지지만 E94 알림은 남는다. 최종 구단의 등록에서 관계를 생성하고 같은 원장으로 알림을 만든다.
- 목표·구종 알림이 base의 과거 시즌에만 생성된다. 최종 시즌에서 기존 refresh 함수를 사용한다.
