# M2-BG — 프로 연도 전환 시작 조건(72 Y01) 읽기 검사

2026-10-21. 설계 72의 연도 전환은 국내·미국·대학·복무 선수 전체를 단계별로 준비한 뒤 한 번에 활성화하는 큰 작업이다. 이번에는 그 첫 단계인 시작 조건 검사만 내 프로 커리어에 읽기 전용으로 구현했다(`kboYearTransitionReadiness`). 실제 나이 증가·계약 이월·새 일정·세계 활성화는 하지 않는다.

- 막는 조건: 시즌 리뷰 단계가 아님, 진행 중 경기, 포스트시즌 미완료(우승팀 없음), 이번 시즌 연말 마감(`seasonClose`) 없음, 열린 사건, 성장 원장 미확정(노쇠 미적용), 내 선수의 다음 나이가 45 초과(14: 모든 리그 공통 최대 45세, 이때는 새 시즌 대신 은퇴·보관 경로).
- 성장·노쇠는 여기서 검사만 하고 다시 적용하지 않는다(72). 대상 시즌 키는 현재+1이다. 조회는 revision·난수를 바꾸지 않는다.

검증: kbo-postseason-progress 3/3(신규: 리뷰 직후 3개 차단→PS 진행 중 단계 차단→PS·성장 후 2개→연말 마감 후 준비 완료, 입력 불변, 45세 차단), lint·타입·build·M1 골든 통과. 순수 읽기 추가라 이번에는 전체 npm run check를 다시 돌리지 않았다. [집중](evidence/M2-BG-focused.log).
