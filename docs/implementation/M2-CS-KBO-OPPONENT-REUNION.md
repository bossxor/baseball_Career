# M2-CS — 실제 상대 출장 재회 E95

2026-10-23. 설계60/107과 기존 사건 E95를 정규시즌·포스트시즌 일 마감에 연결한다. SEPARATED인 라이벌/동료가 같은 실제 경기에서 상대 팀으로 모두 출장한 경우 REUNITED_OPPONENT와 근거 이정표·E95를 한 번 기록한다. 당일 경기 결과와 경기 당시 건강/등록 원장을 교차 확인한다. 현재 소속으로 과거 경기의 팀을 추측하지 않는다.

벤치 등록만 있는 선수·같은 팀·다른 경기·이미 재회/은퇴한 관계는 제외한다. 동종 선수의 비교를 직접 맞대결로 둔갑시키지 않으며 이종 선수도 경기 참석만으로 승리/T14를 만들지 않는다. 경기 결과·세계/RNG·성장·건강은 보존한다. 잘못된 근거는 원자적으로 거절한다.

E95는 비차단 NOTICE이며 진행의 중단 사유를 추가하지 않는다. 기존 E94와 함께 목록을 읽고 OPEN_RELATIONS로 S42를 가리킨다. 확인 시 관계·경기·진행 단계를 바꾸거나 옛 resume.phase를 복원하지 않는다. 공개 DTO는 기존 13개 필드만 내보낸다. 기존 eventKey는 근거 기반 불투명 식별자이며 별도 원장/능력치/잠재력/RNG DTO를 추가하지 않는다.

## 저장 호환·한계

기존 관계 단계와 사건 형식을 사용하며 스키마/의존성 변경은 없다. 완료된 과거 경기의 조회로 재회를 소급 생성하지 않는다. 저장 JSON에서 같은 입력은 같은 결과다. E95를 모르는 구버전 읽기 코드는 이를 거절하므로 새 저장을 옛 실행 파일에서 열 수 있다고 보장하지 않는다. 롤백은 실행 파일과 이전 저장을 함께 보존한다.

상무는 상대 양쪽의 건강 등록 원장이 아직 없어 해당 증거가 없는 군팀 경기를 건너뛴다. 근거를 가공해 보충하지 않는다. 시즌 중 이적 E96은 CT와 공동 완료하며, AI 영입/군팀 공동 등록·NPC 병역·미국 실제 리그·실제 UI/API/계정·DB는 후속이다. 기록 정정으로 원장이 제거되면 공지 조회는 거절하며 전체 정정 트랜잭션은 아직 없다.

사용자가 지정한 ui-ux-pro-max의 ux 검색(nonblocking notification focus)을 py -3으로 확인했다. 기존 디자인을 유지하고 S42 열기 버튼의 가시적 키보드 포커스와 가려지지 않는 접근을 실제 UI 단계에서 검수한다. 이는 향후 UI 검수 항목이며 브라우저 구현/렌더 검수 완료가 아니다. 이번 단계는 비차단·단계 보존·다른 공지 보존을 엔진에서 검사한다. python/python3 별칭 실행은 실패했고 py -3은 성공했다.
