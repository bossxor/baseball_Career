# M2-W — 대학 프리시즌·정규리그 실제 진행

2026-10-21. M2-V의 대학 등록에서 프리시즌 선택→대학 정규216경기→정규리그 검토까지 연결했다. 대학 선수권·연간 성장 정산·학년 마감/진급은 다음 단계이며 현재 `SEASON_REVIEW`가 대학 전체 학년의 완료를 뜻하지 않는다.

## 구현 경계

- `setCollegePreseasonFocus`, `setCollegePreseasonArchetype`, `confirmCollegePreseason`은 ENROLLED 학적·세계 연도·학교·선수/포지션과 revision을 검증한다. 기존 능력/P를 재추첨하지 않고 새 시즌 PRE 기회와 계획 snapshot을 사용한다.
- `advanceCollegeCareer`, `pauseCollegeCareer`, `trainCollegeCareer`은 학교 공통 처리에 연결한다. 기존 고교 전용 진입점은 대학 등록을 계속 거절한다. 공통 경기 준비/게시·일마감·AI 기용·강화·MID·평가·특성은 현재 세계의 `COLLEGE`/시즌을 사용한다. 내부 자료형/파일의 HighSchool 이름은 저장 호환을 위해 유지한다.
- 진행 청크는 PA1000/완료이닝20 한도·pending 경기 난수/커서·1경기/1주일/다음 주요 사건·부상/복귀 정지를 유지한다. 대학에서 고교 최초 집중 E02/E03을 다시 만들지 않고 E43 강화16/E41 MID24는 해당 시즌별로 생성한다. 훈련과 MID는 기존 커리어 공통 조회/사건 명령을 사용하며 연간 사용 이력을 보존한다.
- 공식 기록은 COLLEGE/REGULAR/새 seasonKey로 게시하고 과거 고교 기록·세계 archive를 유지한다. 프리시즌 이후 대학 시즌 중 나이/학년을 자동 증가시키지 않는다. 대학 결과/선수권/성장을 임의 지급하지 않는다.
- 관측 근거에 선택적 `seasonYear`를 추가해 고교의 이전 관측을 보존하면서 새 연도 dayIndex를 비교한다. 기존 고교 근거는 바꾸지 않는다. 같은 연도/날짜 중복, 같은 gameKey의 연도 변조, 시간 역행을 거절한다.
- 특성 커서에 시즌을 기록하고 등록 전환 때 날짜 커서만 새로 연다. 보유/해금 영수증은 유지하며 새 영수증에 리그/시즌을 붙인다. M2-V의 시즌 태그 없는 대학 세이브는 고교 커서 이월로 인식한다. 현재 시즌 정규 조건에 고교 기록을 합산하지 않는다. T14 관계/T16 연속 규정시즌 근거는 여전히 미연결이다.
- 임시 대학 NPC는 M2-V의 학교별 하한/분포·19~22세 기본안D를 재사용하고 `college-temp` 신원을 사용한다. 저장된 생성 난수를 이어 쓰며 복귀 시 등록만 해제한다. 기존 고교 분포·난수 소비는 유지한다.
