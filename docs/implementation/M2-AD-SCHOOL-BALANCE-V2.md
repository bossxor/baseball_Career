# M2-AD — 고교 NPC 평균 중심 분포 버전2

2026-10-21. 사용자 확정은 NPC 종합60 이상 리그 평균약0.5명, NPC 개별 유형 편차 축소다. 사용자는 추가로 플레이어도 평균적인 성장을 해야 하며, 일반적으로53에 도달해 미국 직행이 평범해지는 구성을 원하지 않는다고 정정했다. 따라서 주인공 고교 성장2배 제안은 철회했다. 이어 미국 종합52 문턱을 폐기하고 드문 스카우트 평가 기회로 분리하는 안을 승인했다.

## 구현

- 새 고교 세계는 schoolBalanceVersion:2를 저장한다. NPC 종합은35~65, 평균48/표준편차4 절단 정규분포다. 기존 uniform1개의 조건부 CDF 역변환을 사용해 난수 소비 개수를 유지한다. 경계 clamp로 상한에 밀어 넣거나 학교별 스타 수를 강제하지 않는다.
- NPC 개별 능력은 target×10,000+(유형초기능력-50)×6,000이다. 유형 편차60%는 선택한 축소 방향을 구현한 D다. 유형 강약 순서와6능력 평균을 유지하고 주인공 초기 유형/합300/P는 바꾸지 않는다. 임시 충원도 같은 생성 버전을 사용한다.
- 학교224NPC×200seed=44,800명 실측: 평균49.304→47.990, 신규44~52 비율73.9866%. 신규60 이상74명(표본상 리그 평균0.37명), 종합65는1명이며 모형의60+ 기대 인원은0.4504명/리그다. 200세계 표본 최대 학교별60+는6→2명이다.
- 개별268,800능력 중30 이하 비율5.9193%→0.5357%,70 이상9.9416%→0.4089%. 종합 상한65와 개별 능력 상한100을 구분한다. 대학/프로 초기 분포와 주인공의 일반1.5/하드1/치트3 성장 배율은 그대로다.

## 평균 성장·미국 스카우트 평가

- development.ts/high-school-growth.ts 및 성장 원장 구조는 기존 코드로 되돌렸다. schoolGrowthVersion 같은 신규 성장 필드는 도입하지 않는다. 기존 지급·잠재력·강화/노쇠/구종XP도 변경하지 않는다.
- 미국 최종 평가65 이상을 제안 후보로 사용한다. 기본평가=.5×roleScore+.3×해당 수준 보정성적+.2×스카우팅6능력 잠재력 범위 중앙값 평균. 기존13의 seed 변동[-5,5)을 한 번 적용한다. 종합52·별도 아마평가50 문턱은 없애며, 실제 유효오퍼1개 이상·권리/학적/계약 자격은 필수다. 평균 실력53/성적50/전망75의 기본평가는56.5로 후보 확률0이고, 실력55/성적80/전망75면66.5로 평가 후보 확률65%다. 후자는 오퍼 수락률/MLB 승격 확률이 아니다.
- 현재 미국 진로는 실제 오퍼 생성 전이다. 미국 직행은 마이너 계약부터 시작하며 메이저 출장/승격은 별도다. 종합52 도달성 충돌은 새 자격으로 해소하되 실제 오퍼 생성·저장·만료·서명·마이너 세계 등록은 후속이다. 현재 진로에는 오퍼0이므로 미국 카드를 추가하지 않는다.

## 반복 커리어 차이

- 기존 createCareerPlayer는 일반/하드의 잠재력을 커리어 seed별로 다르게 생성한다. 같은 seed 재현/저장 복원 시 다시 뽑지 않으며 손만 바꿨다고 잠재력을 올리지 않는다. 유형의 초기6능력·집중4 배분과 좌우 matchup, 실제 기용/상대/부상/선택이 경로 차이를 만든다. 새 숨김 성장 배율/희귀 등급/강제 MLB 성장은 추가하지 않는다.
- 100개 seed에서 잠재력 프로필100개와 평균 잠재력 폭10점 초과를 확인했다. 손에 따른 기존 matchup 차이도 확인했다. 이 검사는 생성 차이의 증거이며 완주 후 최상급/보통 선수 비중이나 미국 진출률의 검증이 아니다. 장기 분포는 후속 세계가 연결된 뒤 측정한다.

## 호환·롤백

- 버전 필드가 없는 저장값은1이다. factory 입력 schoolBalanceVersion:1로 과거 세계를 재생하면 출력에 새 필드를 넣지 않아 기존 해시6개가 유지된다. 복원은 저장된 NPC를 재추첨하지 않는다. 알 수 없는 저장 버전은 거절한다.
- 저장된 미국 평가/오퍼는 아직 없고 canShowUsDirect의 사용처는 내부 helper 테스트뿐이다. 이전 overall/amateurScore 입력을 scoutScore로 명시적으로 교체했다. 점수는 추첨 후[-5,105) 범위를 허용한다. 향후 실제 평가 writer는 점수/추첨 상태를 저장하고 preview로 재추첨하지 않는다.

- 새 생성 중단 롤백은 호환 reader를 유지한 채 신규 factory에1을 지정한다. 기존2 세계를1로 덮거나 생성된 능력을 다시 뽑지 않는다. old/new 저장값을 함께 읽으며 파괴적 마이그레이션은 없다.
