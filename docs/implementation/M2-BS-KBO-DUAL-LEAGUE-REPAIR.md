# M2-BS — AI 두 리그 최소 편성 복구

2026-10-22.14의 사용자 결정에 따라 계약상35명 하한은 유지하고1군28명과 별도 퓨처스 경기 편성에 필요한 건강 인원만 안전 보충한다. root 활성화는 후속이다.

## 동작과 기준

기존 개막 기준 야수15/투수13(SP5/RP6/CP2)·포수2·주포지션 적합도100을 사용한다. 별도 퓨처스8수비자리/DH9명과 투수1명이 남아야 하므로 건강 야수24/투수14가 최소다. 주포지션 깊이는 포수3·나머지 수비자리2이며 실제 역할 부족이 있으면38명보다 더 필요할 수 있다. 퓨처스 타순9명을 먼저 보존하고 남은 선수로 기존1군 선택기를 사용한다. 퓨처스에 새5선발 규칙은 추가하지 않는다.

기존 건강한 종합45 이하 독립 대체선수부터 필요한 역할을 최저3천만원/1년으로 계약한다. 해당 역할이 없을 때만35~45·22~30세 독립선수1명을 고정 생성하며 로그를 남긴다. 만료된 가치 높은 전직 프로를 강제로 최저계약하지 않는다. 공용 FA80명은 별도 하한이다.

60명 정원에서 필수 자리 복구가 막힐 때만 기존 부족도를 늘리지 않는 중복 역할 NPC를 정리한다. 주인공 제외·남은 총 보장액이 적은 순/약한 역할 점수/ID순의 구현 D다. 부상/신원/능력/P/구종/이전 계약을 FA에 보존한다. 방출은 돈을 절약하지 않고 자리만 비운다. 새 계약을 개막 전에 방출하면 당해 포함1~4년 전체 보장연봉을 남긴다. 기존 timing 없는 원장은 시즌 종료 뒤 미래1~3년 해석을 유지한다. 부족 예산은 기존44의 실제 당해 지원금만 지급하고 기본120억원을 늘리거나 채무를 삭제하지 않는다.

이 함수는 AI 개인 커리어 세계의 비공개 연도전환 준비다. 사용자 구단 운영 방출·지원 확인 UI나 DB 명령을 대신하지 않는다.
