# M2 E01–E50 실제 도메인 감사 — 2026-11-02

소스·명명된 테스트의 조건과 효과를 읽은 감사다. 새 테스트나 실행을 수행하지 않았다. 문자열 참조를 실행 PASS로 올리지 않는다. 이번 전체 검사 종료 결과는 `M2-RESUMED-VERIFICATION-20261102.md`의 최종 로그를 따른다. 제어 접두 테스트는 전체 native 경력 증거가 아니다.

## 먼저 고칠 실제 연결 결함

1. **E33 나이 조건 누락.** [04](../design/04-EVENTS.md)·[26](../design/26-EVENT-CONTENT-CONTRACT.md)·[카탈로그](../design/event-catalog-v2.json)는 나이≥33과 백업 전환을 함께 요구한다. [kbo-career-fa.ts](../../packages/engine/src/kbo-career-fa.ts)의 `makeEvent`와 `event`는 `offer.role===.5`만 사용한다. 기존 `FA a real backup-role quote opens E33…` 테스트는 `closed()` 기본28세로 E33을 기대해 결함을 고정한다. 33세 미만 백업 제안은 E32의 실제 계약 선택으로 처리하고, 현재33세 이상 백업만 E33/ACCEPT_ROLE로 분기하며 생성·저장 검증을 같은 판정으로 맞춘다. 실제 role=.5와 가격·예산·출전 비보장은 보존한다.
2. **프로0 아마추어 수동 은퇴 owner 부재.** [66](../design/66-RETRY-CAREER-OPPORTUNITIES.md)는 남은 준비 기회가 있어도 허용 마감 시점 수동 은퇴를 허용한다. E06/E07의 REQUEST_RETIRE는 S09 탐색이며 은퇴 자체가 아니다. 실제 E36 생성자는 KBO/US/프로 재도전뿐이다. 학교 root는 [career-retry-exhaustion.ts](../../packages/engine/src/career-retry-exhaustion.ts)의 소진3회 E35만 보유한다. 실제 졸업·미지명/거절 뒤 CAREER_ROUTE 같은 안전 지점에서 아마추어 E36 요청/확인/취소와 프로0 보관이 필요하다. 경기·학기·의무 복무가 진행 중이면 거절하고, 병역 미해결 상태는 그대로 보관해야 한다. 수동 은퇴를 위해3시즌을 먼저 소비하게 만들지 않는다.

E10/11/16/17/18/22/24/27/28은 구현 분기가 실제 존재한다. 아래의 직접 발생/효과 단언 부족을 미구현으로 오해하지 않는다. E34/35의 US 기원·귀국 미지명 후 준비 연결, KBO 배경 staging 한계는 기존 인계의 별도 미완료다.

새 실행이 없는 read-only 감사이므로 이 표의 근거를 새 테스트 통과 수에 더하지 않는다. 소스 분기와 테스트 제목만 있는 항목은 실제 양성/음성 상태·효과를 읽은 범위까지 표시했다. 직접 발생 단언이 없는 사건은 상세 테스트 보강 후 실제 로그/명령 해시에 연결해야 한다. ACK/탐색만 설계된 사건에 계약·능력·의료 효과를 억지로 추가하지 않는다.
