# M2 구현 우선 작업 목록

사용자 지시: 중간 검사 중단, 실제 M2 구현을 모두 채운 후 마지막 통합 검증1회. 아래 “구현”은 소스 연결 상태이고 실행 통과를 뜻하지 않는다. 테스트 코드 작성과 문서·커밋은 계속하며 테스트/시뮬레이션/린트/타입/빌드/검증 스크립트는 실행하지 않는다.

## 이번 구현 묶음 — 실행 검증 이월

귀국 은퇴 소스는 독립 작업 커밋9582294에서 코드/테스트만 통합했다. 해당 worker의 중간 검사는 사용자 지시로 중단했으며 HTTP 검사는 작성만 했다. 통제 복무 prefix를 실제2년 완주 증거로 세지 않는다. 추가 회귀는 `m2-amateur-flow-connections.test.ts`, `us-return-retirement.test.ts`, `m2-us-return-retirement.test.ts`에 작성했고 아직 실행하지 않았다.

## 이어서 채울 구현

- 고교·대학의 나머지 사건/국가대표/병역/재도전 공개 명령이 실제 화면에서 선택 가능한지 코드에서 빠진 호출자를 연결한다. 이미 구현한 계약·미국 귀국·재회 기능을 낡은 인계만 보고 다시 만들지 않는다.
- 실제 누락 기능과 단순 미검증/증거 부족을 구분한다.24경로 실행 해시·99사건 증명·PF-D·실기기·성능 측정은 최종 검증 목록이며 지금 시뮬레이션을 실행하지 않는다.
- M6·미결정134·능력 상한 변경은 이 작업에 섞지 않는다. 실제 새 게임 규칙의 미정 수치만 사용자에게 묻는다.

## 검사 기록

검증 중단 이전의 분할 저장 근거는 [저장 구현](M2-SPLIT-SAVE-20261110.md)에 보존한다. 위 새 연결 코드에 그 통과 수를 재사용하지 않는다. 전체 중단 실행은 CANCELLED_BY_USER로 보존하며 현재 M2 전체를 PASS로 표시하지 않는다.
