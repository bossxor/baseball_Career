# M2-AR — 프로 관계 조회와 알림 읽음

## 구조와 동작

공통 관계 집계는 세계 전체 대신 신원/팀/기록의 최소 읽기 문맥을 받는다. 기존 고교/대학 DTO·실패/정렬 규칙은 유지한다. E94 원본 검증/이벤트 해결만 prepareRelationNoticeRead로 공유하고, 각 루트가 revision/phase/연말 봉인을 소유한다. 반환 알림은 복사해 미선택 사건 객체가 이전 저장값과 공유되지 않게 했다.

프로 adapter는 실제 KBO 구단/선수단과 amateurHistory의 과거 학년 세계·최종 학교 세계를 조회한다. 과거 선수를 활성 프로 선수단에 복사하거나 NPC 진로/등록·분리/은퇴를 추정하지 않는다. 마지막 확인 소속은 원래 리그/시즌/팀으로 표시하고 누락 신원은 UNKNOWN_REFERENCE로 남긴다. 프로 DTO는 학교·구단 공통 teamName을 쓰며 기존 학교 API의 schoolName은 유지한다.

같은 종류는 실제 공식 기여 기록의 동시 출장 경기 비교, 다른 종류는 기존 실제 타석 직접 집계를 공유한다. 리그/정규/PS/연도를 섞지 않고 프로 기록0을 가짜 경기로 채우지 않는다. 각 읽기 DTO는 이름/손/폼·관계/기록만 제공하며 능력/P/RNG/봉인 원본을 반환하지 않는다.

resolveKboRelationNotice는 알림 읽음/revision과 S42 탐색 대상만 바꾼다. 확정 프리시즌 계획·현재 능력/선수단·기록/건강·캠프 알림·amateurHistory를 그대로 보존하며 과거 resumePhase를 복원하지 않는다. 잘못된 사건/중복·버전/명령과 훼손된 계획은 거절한다.
