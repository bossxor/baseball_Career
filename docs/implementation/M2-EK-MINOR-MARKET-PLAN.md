# M2-EK 계획 — 마이너 만료 비교와 E66 조회

EJ 이후 새 KBO 마이너 계약이 서명 기간을 마친 상태에서 실제 비교 자료를 봉인한다. 신설 숫자는 없고 사용자 확정1년/$30,000, 현재 레벨 유지, 원구단+조건을 충족한 타 구단 최대3곳·국내 복귀를 따른다. 타 구단 수요는 기존 US 경쟁 점수/동포지션 최저 점수 비교를 재사용한다.

새 openUsMinorMarket은 기존 연말 준비/기록 감사를 통과해야 생성한다. trusted 연간 funding을 검증하고 실제 원장 예산과 현재 레벨 선수들로 후보를 만든다. 한 번 생성된 제안은 저장/재조회로 재추첨하지 않는다. 같은 비교 창의 E66을1회 만들고 두 NAVIGATE 명령은 실제 미국 제안 목록과 국내 보유권별 복귀 검토 자료로 연결한다. 조회만으로 계약/급여/세계/사건 완료가 바뀌면 안 된다.

경쟁 점수를 계산할 때 현재 리그/시즌 합계는1회 집계하고 모든 후보가 재사용한다. 지속 캐시나 숨김 잠재력 조회는 추가하지 않는다. root reader는 봉인 창의 구조·조건·사건 바인딩을 검증하고 구 저장에는 새 필드를 요구하지 않는다.

계약 수락·새해 금융 재생·조직 이동·US→KBO 세계 인계는 이번 조회 묶음의 완료 범위가 아니다. E66도 전체 커리어/화면 완료로 올리지 않는다. 현재 조회 경로를 실제 데이터/실행으로 검증하고 다음 writer가 사용할 원장을 제공한다. 프런트/M6 구현은 하지 않는다.

집중 테스트는 최초 부재/틀린 동작 실패 확인, 봉인/JSON 재개/확률 없는 확정 조건·E66 두 조회/예산 부족/변조·조기 진입 거부를 포함한다. 마지막 전체 npm run check·HTTP 스모크와 증거를 남긴 뒤 문서·V 문서 복사·own branch 커밋/푸시한다.
