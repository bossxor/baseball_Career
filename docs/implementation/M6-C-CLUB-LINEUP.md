# M6-C — 손으로 만든 라인업을 실제 경기에 적용 (S15)

2026-10-26. M6-A의 라인업 검사는 읽기뿐이었다. 이제 구단주가 정한 타순·수비 배치·선발 투수가 내 구단의 1군 경기에 그대로 쓰인다. 새 수치 없음(05의 적합도 배율 .5~1.0을 그대로 사용: 본래 포지션 fit 100, 그 밖은 fit 0 = 자동 편성과 같은 규칙). 브랜치 `m6/club-mode`.

- **엔진(공유 코드, 추가만)**: `HighSchoolGameContext.lineupOverrides`(팀별 타순·포지션별 수비수·DH). 준비 단계에서 서로 다른 건강한 타자 9명·한 포지션당 1명+DH·좌투의 포수/2·3루/유격수 불가·타순이 같은 9명인지를 검사하고 어기면 `INVALID_GAME_CONTEXT`. 지정이 없으면 기존 자동 편성 그대로다.
- **`applyKboClubLineup` / `clearKboClubLineup`**: 문제 없는 라인업만 저장(`CLUB_LINEUP_INVALID`), 저장 뒤에는 내 구단 1군(KBO) 모든 경기에 쓰인다. 퓨처스 경기는 자동 편성이다. 해제하면 자동으로 돌아간다. 개정 번호가 다르면 `CLUB_GAME_REVISION_CHANGED`.
- **경기 전 검증**: `advanceKboClubGame`은 내 구단의 다음 1군 경기를 준비하기 전에 저장 라인업을 다시 검사하고, 부상 등으로 무효가 되었으면 경기를 치르지 않고 `LINEUP_INVALID`로 멈춘다(조용히 바꾸지 않음). 사용자는 새 라인업을 적용하거나 해제해 이어간다.
- **선발 규칙**: 건강한 SP가 있는데 SP가 아닌 투수를 선발로 지정하면 `STARTER_MUST_BE_SP`(게임 엔진 규칙과 일치).
