# M2 완료 범위와 이어갈 순서 — 2026-10-26

사용자는 M2 완료까지 계속 구현하도록 요청했다. 이 문서는 완료 선언이 아니다.120의 M2 범위는 생성→고교→드래프트/대학/미국→프로→은퇴,99개 사건의 실제 도메인 연결, 특성·구종·목표·관계 효과,24개 통합 경로 해시와119 PF-D 검수다. 정의표나 정적 설계 PASS는 실제 플레이 완료가 아니다. M3는 다른 환경에서 병행하며 여기서는 인증/DB/저장 API를 구현하지 않는다. 다른 환경은 packages/engine과 M2 문서를 직접 수정하지 않는다.
