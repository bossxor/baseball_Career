# M2-BU — FA·은퇴 관계 신원 읽기

2026-10-22. 관계 상대가 FA/은퇴 아카이브로 이동해도 이름/손/폼/공식 범위별 비교를 잃지 않도록 선택적 detachedPlayers 읽기 어댑터를 추가했다. 현재 로스터/등록/phase/관계 단계는 변경하지 않는다. 기존 프로 PRE 읽기 범위이며 시즌중 모든 화면의 일반 조회까지 확장한 것이 아니다.

EXPIRED는 저장된 이전 활성 계약의 알려진 구단/시즌을 사용한다. 개막 전 계약 직후 방출될 수도 있는 RELEASED는 계약 구단을 지난 등록 팀으로 꾸미지 않는다. 알려진 등록이 없는 방출/무소속 은퇴는 실제 KBO/퓨처스 공식 경기와 health 등록 근거가 있으면 마지막 등록을 복구하고, 없으면 팀은 null이다. 은퇴 NPC의 마지막 활성 구단/시즌은 기존 은퇴 snapshot을 쓴다. 학창 이력 조회는 그대로 유지한다.

숨김 P/seed/능력 원본은 DTO에 포함하지 않고 HISTORICAL_ONLY와 기존 비교 로직을 재사용한다. E94 알림의 상대 이름도 보존하되 현재 소속으로 표시하지 않는다. 재회/분리/은퇴 관계 사건의 자동 전이는 후속이다.

최종 관계8건 통과(M2-BW-final-read-tests.log의8건, 은퇴조회4건과 합계12/12). 이전 전체457/457 후 방출 등록 근거 보강을 추가했으므로 이 최종8건은 별도 증거다. 원본/계획/이력 불변, 옛 저장값, JSON, 공개 allowlist와 실제 등록 근거 없는 구단 노출 금지를 확인했다.
