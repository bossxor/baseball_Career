# M2-K 부상·최소 임시 충원 기반

2026-10-20. 사용자 승인: 고교 부상으로 경기 인원이 모자라면 필요한 만큼만 임시 충원하고 원선수 복귀 시 제외한다. 14에 승인,69에 경기 후 처리 기준을 기록했다.

- 실제 출장자당 경기 후1회0.15%, 위험도 snapshot의 피로80초과면0.3%. 출장하지 않으면 부상 RNG를 쓰지 않는다. 경증80%/중등도18%/중상2%, 회복3~7/8~30팀경기/남은 시즌. 단순 달력 휴식으로 줄이지 않는다.
- 진단 경기 자체는 회복을 소모하지 않는다. 등록된 팀의 이후 실제 경기에서만 줄인다. 같은 근거 재처리는 RNG·회복0이며 변경 근거·부상 중 출장·같은 날 중복 등록경기·과거 경기 삽입을 거절한다. 중상 시즌 마감 해제는1회이며 경증/중등도 잔여를 삭제하지 않는다.
- 최소 야수9명·좌투 금지4수비에 필요한 우투4명·투수1명을 계산한다. 임시 우투를 먼저 확보해 좌투 임시 선수와 신규 우투가 불필요하게 중복되지 않게 한다. 회복한 원선수를 우선하고 초과/부상 임시 선수는 등록 해제 대상으로 반환한다. 선수 신원/공식 기록을 삭제하지 않는다.
- 초기 세계9팀/225명/학교25명 생성 검사는 그대로 유지한다. 진행 중 임시 등록과 선수 생성은 상위 세계 transaction이 담당한다.
