## 변경

- 실제 복무 시즌의 상무 대여 선수는 `SANGMU/FUTURES`로 새 목표의 팀·리그를 봉인한다. 중반 교체 창도 원구단이 아닌 봉인된 상무 정규 72경기로 연다. FUTURES에는 G09 팀 포스트시즌 목표를 제안하지 않는다.
- 현역 계약의 지급 정지가 실제 활성 상태면 새 목표 선택과 중반 교체를 막는다. 공개 DTO의 `registration`은 팀/리그 `null`, `selection`과 `replacement`의 사유는 `SERVING_ACTIVE`다. 추천/선택 가능 정의는 빈 목록이다. 선택 명령을 호출하지 않아도 기존 시즌 진행은 가능하다. 빈 선택 명령도 `GOAL_SELECTION_UNAVAILABLE`로 거부해 가짜 민간 등록 시즌 원장을 만들지 않는다.
- 과거 슬롯·scope·이력·보상·교체 사용량을 지우거나 재봉인하지 않는다. 복귀 뒤 현재 민간 등록과 자격을 다시 읽으며, 상무에서 이미 봉인한 목표의 팀은 그대로 유지한다. 아직 시작하지 않은 다음 시즌 복무 예약은 현재 민간 자격을 바꾸지 않는다.
- 기존 `kboActiveContractSuspended`, 상무 팀 상수와 대여/복무 블록을 재사용했다. 새 저장 스키마·의존성·계정 보상 처리는 없다. 기존 목표 공개 API의 반환 필드만 추가했다. 저장 필드 없는 구 저장은 그대로 진행한다.
