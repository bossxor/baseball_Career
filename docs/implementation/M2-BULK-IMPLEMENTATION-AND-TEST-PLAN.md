# M2 일괄 구현·통합 검증 계획

2026-10-28 사용자 지시 변경. 작은 단계마다 전체 npm run check를 반복하지 않는다. 남은 M2를 기능군으로 이어 구현하고, 전체 구현 묶음이 끝나면 전체 검사를 한 번 실행한다. 실패는 기능군별로 수정하고 영향 있는 검사만 재실행한다.

## 상태 표기

- 구현 중: 실행 코드 연결이 아직 끝나지 않았다.
- 구현 완료·검증 대기: 코드 연결은 끝났지만 통합 실행을 아직 확인하지 않았다.
- 검증 통과: 실제 실행 로그가 있다. 통제 fixture/실제 경기/기기 증거는 구분한다.

최신 검증 완료 기준은271900f(EL)이다. 이후 변경을 이 기준의 통과 수에 합치지 않는다. STATUS의60%는 이전 범위 추정이며 새 테스트 수를 진행률로 환산하지 않는다.

## 중간 확인 원칙

전체 테스트는 보류한다. 타입/문법·정적 연결과 데이터 보존에 직접 관련된 짧은 확인만 필요할 때 수행한다. 테스트는 함께 작성하되 실행 대기 목록에 등록한다. 이미 실행한 결과는 그대로 보존한다. 검증 전 기능을 최종 완료로 보고하지 않는다.
