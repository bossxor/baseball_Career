## 승인 범위와 연결

사용자 승인: 부상으로 건강한 야수9·투수1이 부족할 때 군팀 전용 임시선수로 최소 보충하고 정규 선수 복귀 시 제외한다. 추가 승인: 기존 KBO 비상 대체 선수 수준인 종합35~45. 정규 연간 야수10·투수10 선발, 민간 계약/정원, 개인 병역 판정과 분리한다.

기존 planEmergencyRoster의 야수9·투수1·우투 중요 수비수4명 계산과 기존 KBO 비상 대체 프로필 생성 함수를 재사용한다. 프로필의 성인 나이22~30·유형별 분배·잠재력/손/구종 생성은 기존 비상 대체 방식과 같다. 임시선수에 가짜 복무 프로그램·계약을 만들지 않는다.

책임 경로: 시즌 시작 → 군팀 원장 활성화 → 신규 경기 준비 전 최소 충원/제외 → 두 리그 투영 → 실제 경기/구종XP 커밋 → 하루1회 피로 및 FUTURES:SANGMU 등록 건강 → 원래 선수 회복 → 다음 경기 준비 시 불필요 임시선수 제외. 제외 시 신원/구종/과거 출장 증거는 삭제하지 않는다. 연도 전환 시 활성 임시 등록을 종료하고 보관한다.

군팀 멤버와 임시선수의 관계 신원 조회도 별도 읽기 투영으로 연결한다. 현재 군팀 소속은 FUTURES/상무, 제외된 임시선수는 과거 신원과 실제 건강 등록/공식 기록에 근거한 당시 상무를 표시한다. 실제 민간 선수 원장/등록은 바꾸지 않는다.

## 호환성과 롤백

KBO 루트v5: 새 상무 시즌의 startKboRegularSeason만 건강/비상 원장을 활성화한다. 이미 진행 중이고 원장이 없는 v1~v4 저장은 소급 활성화하지 않고 기존 군팀 건강 추첨 생략/난수 순서를 유지한다. 이후 새 시즌 시작에서만 전환한다. 단순 조회·JSON 복원은 등록/사건/RNG를 바꾸지 않는다.

v5 상태를v4로 표시한 변조는 명령 가드에서 거부한다. 이적/보관/연도 전환 읽기 및 이적 쓰기는v5를 허용/보존한다. 새 저장을 구버전 바이너리에서 실행하는 것은 지원하지 않는다. 롤백은 배포 전 코드와 저장 스냅샷을 함께 보존한다. 기존 저장을 덮어쓰거나 축소하는 마이그레이션은 없다.
