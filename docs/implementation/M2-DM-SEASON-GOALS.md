# M2-DM — 시즌 목표10종·기념 보상 엔진

2026-10-27.49/58/102의 시즌 목표를 학교·KBO·미국 엔진에 연결했다. 커리어 도전12종/계정 DB/외형 장착/실제 UI는 이 묶음의 완료 범위가 아니다.

## 동작

- PRE 최대3개/0개 허용·종류/현재 리그 자격 검사·첫 정규 경기 이후 잠금. 반시즌의 미완료 슬롯1개만 교체, 교체 이력·세계 시즌 사용량 보존. 승강으로 최초 리그의 반시즌 창을 재생성하지 않는다. 이미 목표치를 채운 신규 MID 목표와 완료 슬롯 재사용을 거부한다.
- G01 PA50/G02 선발50/G03 HR20/G04 BB30/G05 K100/G06 선발아웃300/G07 SV20/G08 실제 부상·회복 후 출장/G09 선택팀 정규 등록과 최종 PS 자격/G10 대학선수권 PA/BF를 실제 원장으로 계산한다. 원래 시즌·리그·정규/PS를 고정하며 다른 리그/구원 아웃/단순 복귀 버튼을 합산하지 않는다. 현재 v1은 고정 타순이라 타자 games=선발이다. 대타를 도입하기 전에 별도 starts 원장을 추가해야 한다(shortcut 주석).
- 추천은 전년 같은 리그 실적/목표 비율.5~1.2 우선→현재 진척→ID. 무표본은 기존 입문 기본안을 자격 필터링한다. 근거 없는 달성 확률은 만들지 않는다. 공개 DTO는 제목/단위/범위/현재값/목표/교체/치트 출처를 제공하고 내부 잠재력/RNG를 노출하지 않는다. 반환한 scope/보상 sources를 수정해도 원본이 바뀌지 않는다.
- 완료 영수증·기념 보상·E90 outbox를 같은 결과에 남긴다. 능력/잠재력/돈/강화/구종XP 변화0. 같은 보상은 이 선수 원장에1개, 추가 달성 출처만 보존한다. 기록 정정은 CORRECTED/새 소식을 남기되 기념 외형 회수/대체 재화 없음. 계정 전체 보상 UNIQUE/소식 읽기·배송은 M3 소비자 책임이며 이 엔진에서 DB 처리 완료로 주장하지 않는다.
- E90은 필수 선택 큐에 넣지 않는 불변 outbox다. 조회가 게임 root를 수정하거나 마감 영수증을 깨지 않게 한다. 경기/선수권/PS·연말/이월/은퇴의 기존 커밋 경로에서만 정산한다. 마감 해시는 목표 정산 뒤 봉인한다. 기존 목표 필드 없는1~7 저장은 기존 경로 그대로이며 goals가 없으면 정산은 동일 객체를 반환한다.
