## 실제 문제와 수정 범위

군팀 임시선수 연도 이월 자기검사에서 실제 한국시리즈 마지막 경기의 주인공 부상 후 처음 정규 성장 정산을 요청하면 CHANGED_GROWTH_HEALTH_EVIDENCE가 발생했다. 정규 성장의 마지막 부상 상태를 포스트시즌까지 지난 현재 health.injuries와 직접 비교한 것이 원인이다. [수정 전 재현](evidence/M2-CV-before-fix.log). 정규 경기는 통제된 시계, 포스트시즌은 실제 명령으로 재현했다.

정규·병역 기간 분할 두 호출자는 공통 kboRegularEndInjured를 사용한다. 현재 부상 상태에서 정규 범위 뒤의 마감된 날짜만 역순으로 되돌려 정규 마지막 상태와 비교한다. 진단/회복 모순과 같은 날 양쪽 전이는 계속 거부한다. 실제 부상·일정·피로·출장·기록·RNG와 이전 지급 영수증은 수정하지 않는다. 정규 성장의 수치·능력/잠재력·기간·연간 한도·시작 상태 계산은 기존 규칙이다. 이미 지급한 기간과 다른 증거는 기존 GROWTH_EVIDENCE_REUSED 검사로 거부한다.

새 저장 스키마·DB 마이그레이션·새 게임 규칙은 없다. 단순 조회로 과거 성장/부상을 소급 지급하거나 지우지 않는다.

## 범위 제한

정규 기간 시작 시 이전 시즌 부상을 추론하는 기존 계산은 바꾸지 않는다. 이미 지급된 기간을 재작성하지 않는 범위에서, 이전 시즌 부상이 포스트시즌에 회복된 경우의 시작 재활 계산은 후속 감사가 필요하다. NPC6월30일 복귀·급여·성장, UI/계정/클라우드/APK는 이번 범위가 아니다.


## 후속 감사 단서 — 코드 변경 없음

추가 읽기 조사에서 KBO openingRoster.sourceBasis가 이미 개막 unavailable 목록을 보존함을 확인했다. 대학의 openingRehabilitation처럼 시즌 시작 부상을 증명할 수 있어 시즌 말 현재 injuries에서 추측할 필요가 없다. CV는 기존 지급 기간을 재작성하지 않도록 시작 계산을 유지한다. 다음 마일스톤은 실제 등록 경기에서 이전 부상이 회복되는 사례를 먼저 재현하고, 미정산 새 기간이 개막 증거를 쓰는 호환 경로를 확인한다. 옛 periodKey/금액은 보존한다. 새 계산을 도입하면 기간 키의 명시 버전 접미사를 재사용할 수 있으나 옛 기간을 조용히 바꾸거나 changed-evidence 검사를 건너뛰지 않는다. 이 문단은 조사이며 수정/통과 증거가 아니다.
