# M6-B — 내 선수 사용(보관 투입) 새 구단 게임

2026-10-26. 05/32의 "내 선수 사용 ON": 은퇴해 보관된 프로 커리어를 새 구단 게임에 19세 복사본으로 투입한다. 원본은 불변이며 새 게임 수치/확률은 만들지 않고 32의 제안식(D)을 그대로 쓴다. 브랜치 `m6/club-mode`.

- **`archivedPlayerOf(career)`**: ARCHIVED 상태 프로 커리어에서 허용된 필드(이름·종류·포지션·투타·투구폼·유형·최종 능력·커리어 최고값·최종 잠재력·가장 높은 변화구)만 읽는 보관 스냅샷. 은퇴 전 커리어는 `ARCHIVE_NOT_READY`, 최고값 증거가 없으면 투입 보류(`ARCHIVE_PEAKS_REQUIRED`, 은퇴 능력을 최고값으로 대입하지 않는다).
- **`importedPlayerOf`**: 능력 = 최고값의 50%(능력별, 1점 하한), 나이 19·피로 0·기록/프로 연차 0·투타/투구폼/유형은 원본 승계, 집중 4개는 다시 선택(`assertFocus`). 새 잠재력 = min(100, max(최고값, 원 잠재력) + 5~10점)을 import 초안 id와 보관 id로 고정한 난수에서 뽑아 화면을 다시 열거나 재시도해도 변하지 않는다. 병역·메달·대표 이력은 복사본에 없다(출처로만 남음).
- **`importReplacementCandidates`**: 내 구단의 같은 종류·같은 포지션(투수는 같은 보직) 선수 중 경쟁 점수가 낮은 순. 비어 있으면 그 보관 선수는 투입할 수 없다.
- **`importArchivedPlayers` / `createKboClubGame({imports})`**: 최대 28명을 한 번에 처리한다. 복사본은 대체 선수의 1군/2군 자리를 그대로 받고, 1년 최저연봉 계약(구단 연봉 예약 갱신), 투수는 새 2구종 책(원본의 가장 높은 변화구). 대체된 선수는 **자유계약 풀**로 이동(`RELEASED`, 이전 구단·계약 이력 보존)하며 풀은 새 구단 게임부터 최소 80명으로 존재한다. 생성 중 설정 단계의 대체이므로 대체 계약은 체결되지 않은 것으로 보고 보장액을 남기지 않는다. 결과 구단이 합법 1군을 구성하지 못하면 `IMPORT_COMPOSITION_INVALID`로 거절한다(조용히 고치지 않음). 같은 입력은 같은 게임, 생성 키에 선택 내용이 포함된다. 다른 구단은 변하지 않는다.
