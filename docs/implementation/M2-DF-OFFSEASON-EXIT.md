사용자는 다음 해 보유권 해제 후 타 구단1년 제안 비교를 확정했다. 정상적인 원구단 재계약은 유지하고 예산 부족 때 기존 offerKboRenewal 진입점에서 비교를 연다. 원래 시즌 소속/권리/게임/지급 원장은 그대로 두며 E30을 수락한 다음 실제 Y02에서만 새 계약과 FREE_AGENT 권리를 활성화한다. 기존 AI 오프시즌이 만료 NPC와 공급/정원/필수 명단을 정리하기 전에 선택 선수의 자리/급여를 확보한다.60명이라도 실제 만료 예정 자리가 있으면 제안할 수 있고 보장 선수60명이면 제외한다.

구종/기록/P/성장 정산을 보존하고 다음 시즌은 나이만1세 증가한다. 기존 관계 종류·이력과 옛 팀 분리를 유지하고 새 팀 첫 등록의 동료를 기존 helper로 만든다. 기존 다른 경로 E96의 의미를 변경하지 않는다. 새 개인 오프시즌 계약을 근거로 한 기존 분리 상대의 실제 경기 E96은 별도 후속 검증 범위다.

읽기/비교/JSON 재개·E30버전/제안 금액/대상 예산/도메인 영수증 변조 거부·실제 Y02/양 리그 명단·현역/상무 미래 계약 소속을 검증한다. 정규 시계 일부는 통제한 fixture이며18개월 전체 검증은 아니다. 상대 구단 오퍼0개면 진행 차단과 기존 명시 은퇴만 제공한다. 실제 UI/API 저장/Neon/APK는 포함하지 않는다.
