# M2-AK — 동료 20경기 공존 이정표

2026-10-21. [60](../design/60-RELATIONS-DETAILED-CONTRACT.md)·[51](../design/51-RIVALS-TEAMMATES.md)의 동료 첫 이정표를 일마감에 연결했다. 새 게임 규칙은 추가하지 않았다.

- `refreshRelationMilestones`: 동료 관계에서 두 선수가 모두 내 학교 명단에 있고, 같은 시즌 정규 팀 경기 날짜(같은 날 1회, 휴식·우천일 제외)가 20일이 되면 `COEXIST_20` 이정표를 한 번 추가한다. 날짜는 20번째 공동 경기일, evidenceKey는 관계·시즌 기준이다.
- 고교 정규 명단은 시즌 중 바뀌지 않으므로(임시 충원만 추가·해제) 현재 명단 소속을 각 경기일의 등록으로 본다. 상대가 명단에 없으면 추가하지 않는다. 라이벌 관계는 영향이 없다. 단계(stage)는 FORMED를 유지한다.
- 고교/대학 정규 진행의 일마감마다 갱신한다. 이미 있는 이정표는 다시 만들지 않는다.

검증: 관계 6/6(19일 미달·20일 정확 1회·재처리0·라이벌 무영향·명단 이탈 시 미추가)과 사건 알림·특성·고교216경기·대학·선수권 경로 포함 39/39(1112.0초), 소스/테스트 타입·lint·build·M1 골든 통과. 이번에는 npm run check 전체를 다시 돌리지 않았고 이벤트 동기화·설계 정적10종도 재실행하지 않았다(해당 파일 변경 없음). [집중](evidence/M2-AK-focused.log).

미완료: 첫 동반 PS·우승·이적 후 재회 이정표, 분리/재회/은퇴 단계 전이, 대학·프로에서의 동료 재형성, 이정표 기반 연대기 장면.
