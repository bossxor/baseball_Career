## 재개 우선순위

- checkpoint 린트/타입 통과와 전체 runtime 통과를 구분한다. 이전 readonly 테스트 타입 오류는 새 필드 객체로 치환해 고쳤고 RED 로그도 보존했다.
- 프로 재도전 실패 fixture를 음수 제안 경로와 실제 재원 있는 양수 수락 경로로 분리한다. 제안을 강제로 만들지 않는다. E35는 실제 합법 경로·군 의무를 모두 확인하고 명시적 은퇴를 실행해야 한다.
- US 직접 진출 원천의 실제 release/re-sign 시장과 새 연속 계약 epoch가 아직 없다. 취소를 호출자 boolean이나 가짜 만료로 증명하지 않는다. 중지된 native2시즌은 새 실행/안전 재개로 증명하고 기존 원본·세계·급여·건강·구종을 보존한다.
- 새 root API는 아직 패키지 index/실제 호출부에 통합되지 않았다. 부모 호출 차단, 아카이브/후속 정상 플레이, 두 소유자 결과의 권한 검증을 완료한 뒤 노출한다.
- 전체 M2 경로 runner를 실제 명령과 입력/출력 해시로 완성한다. 통제 접두와 native 구간을 명시하고 M3/M6/M7/기기 의존을 PASS로 처리하지 않는다.
- 모든 M2 요구를 채운 뒤 소스 동결, 새 전체 check·리뷰·증거/진행 업데이트·커밋/푸시. 작은 묶음 통과를 M2 완료로 대체하지 않는다.
