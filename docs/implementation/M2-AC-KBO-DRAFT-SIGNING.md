# M2-AC — 커리어 KBO 지명·신인 계약 예약

2026-10-21. M2-AB의 실제 구단/가상 선수단을 이용해 첫 국내 지명 미리보기·고정 결과·신인 계약/보유권/다음 시즌 등록·연봉 예약을 연결한다. 프로 경기·연말 마감/실제 다음 시즌 활성화는 별도 단계다.

## 구현 범위

- kbo-draft.ts는 현재 선수단의 유일 소속/활성 계약·현재 연봉 합계/미래 보장액을 검증한다. 초기50명/연령 비율을 강요하는 assertInitialKboWorld를 영입 가능성 검사에 재사용하지 않는다. 정원60명·최저연봉 여력·목표 시즌90% 보장 상한을 확인한다. 슬롯0은 사유와0%를 반환하고 추첨 난수를 소모하지 않는다.
- 확률/라운드는34의 기존 preview/draw를 공유한다. assessmentKey와 해당 세계/대상 시즌의 별도 stream을 사용한다. 조회는 난수/버전 불변, 실제 지명 결과는1회 저장한다. 결과/원본 로스터·평가·난수 변경과 낡은 버전은 거절한다. 결과 재조회·JSON 복원으로 재추첨하지 않는다.
- 구단은 포지션 필수/백업 수요100/50/10, 같은 수요면 해당 보직의 경쟁 경계 역할점수가 낮은 구단 순이다. 희망 구단은 수요와 역할점수가 같은 경우에만 반영하고 마지막 동률은 안정된 구단 ID로 푼다. 초기 필요 인원 C2/SP5/구원 RP+CP8/나머지 야수1은 기존44/14의 편성 조건을 사용한다. 계약 없는 구단/선호 구단을 이름만으로 보장하지 않는다.
- 지명 결과와 계약은 별도 확정이다. 05/44에 따라1년/최저3천만원/계약금0원, 통화KRW다. 수락은 계약·국내 DRAFT 보유권·등록 예약·구단의 실효 로스터51명/연봉 예약30,000,000원 증가를 단일 signing 영수증에 저장한다. 계약 전에 서명한 것으로 처리하거나1군 기용/출장을 보장하지 않는다.
- 기초500명 세계는 불변이다. signing.rosterAfter 및 reservedSalaryBefore/After가 이 신인의 권위 있는 추가 예약 원장이다. 다음 시즌 활성화 작업자는 이 영수증을1회 실제 프로 세계에 반영해야 하며 기초 세계의50명/90억원만 읽어 예약을 누락하거나 signing과 중복 합산하면 안 된다. 아직501명 프로 경기 세계를 가동한 것이 아니다.
- career-kbo.ts는 졸업 진로를 검증하고 다음 연도 프로 세계와 프로그램을 준비한다. 고교는 기존 역할평가/고교 성적, 대학4학년 졸업은43의 종합/보정 성적(-18)을 공유한다. 평가 helper를 재사용해 조회와 확정의 기준을 맞췄다. 학년1~3과 졸업 미확정 상태에서 대학 졸업 드래프트를 실행할 수 없다.
- 고교 수락은 실제 signing 영수증으로 E04를 완료하고 NEXT_SEASON_READY/KBO가 된다. 대학은 이미 확정한 E75/GRADUATED를 유지한다. 학교 세계/정규·선수권 기록/6능력·P/성장/강화/구종·건강/나이를 바꾸지 않는다. 당해 학교 미사용 강화를 몰래 포기하거나 내년 나이를 미리 올리지 않는다.
- 고교 계약 거절은 E04/대학 진학 선택을 유지한다. 대학 입학 시 해당 프로그램은 이전 모집 이력으로 보관하고 활성 참조를 해제한다. 과거 KBO 평가 세계가 있는 선수를 수년 후 다시 평가하는 경로는 리그 연도 갱신이 연결되기 전에는 새500명을 몰래 재생성하지 않고 명시적으로 차단한다.
- 공개 조회는 명시적 allowlist다. 숨김 P/seed/RNG/sourceBasis와 선수단 전체를 반환하지 않는다. 확률1의 UI 배지 숨김은 실제 플레이 UI를 연결할 때38에 따라 적용한다.

## 검증

최종 관련 회귀38/38(106.3초), 전체 워크스페이스/테스트 타입·린트·빌드, compiled M1 골든, 이벤트 동기화·설계 정적10종·HTTP smoke를 통과했다. 고교 타자/투수의 실제 진로 명령부터 서명·예약·E04 완료까지, 대학4년 fixture/실제 선수권 후 E75 졸업→대학 보정 평가→지명→서명을 검사했다. 대학4년 전체864경기를 실제 시뮬레이션했다는 뜻은 아니다. 정원60/목표연도90% 상한의0%·무추첨, 수요 우선/선호 동률, JSON 재개/재조회·중복 서명 거절과 기존 대학 입학/진급을 확인했다. 이번 단계에서 전체 테스트 묶음은 재실행하지 않았다. 직전252개 전체 기준 검사와 M2-AB 신규6개 결과는 해당 단계 증거를 참조한다. 첫 집중 실행에서 선택 필드의 undefined를 canonicalJson에 넣은 오류를 발견했고, 명시적 null로 고쳤다. 기존 canonicalJson의 엄격 검증은 완화하지 않았다.
