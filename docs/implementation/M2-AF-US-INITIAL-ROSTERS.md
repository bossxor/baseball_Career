# M2-AF — 미국 초기 선수단과 모집 재고 연결

2026-10-21. 사용자는 각 레벨 평균35/45/55/65/75, 절단 전 표준편차4·평균±8의 종 모양 초기 분포를 확정했다. 실제 P/성장·치트·미국 진출 자격은 바꾸지 않는다.

## 구현과 근거

- us-world.ts의 createUsRosterWorld는 호출자가 제공한30조직 ID/표시명을 검증해 정렬하고 조직마다 Rookie/A/AA/AAA22명과 MLB26명, 총3,420명의 가상 NPC를 생성한다. 투수1,590명의 구종 book/XP 원장도 함께 만든다. 공식 구단명/로고를 임의로 만들어 공식 자산인 것처럼 표시하지 않는다.
- 평균+4×z에서 z는 기존 truncatedNormal의[-2,2] 조건부 표준정규다. 정수 목표 종합을 고정한 후 유형별6능력 배분·수학적 상한을 적용해 정확한 평균과1~100을 유지한다. 경계 clamp로 극단값을 쌓거나 학교/구단별 스타 수를 보장하지 않는다. 절단 후 실제 표준편차는4보다 작다.
- 기존 NPC 손/타석/폼, 숨김 P/하드 NPC P 보너스, 집중4,구종 생성기를 재사용한다. 미국 경쟁자에게 개인 치트의 P100·성장3배를 잘못 적용하지 않는다. 같은 seed/입력은 조직 입력 순서와 관계없이 같은 세계가 된다.
- 나이/포지션 구성의 D는 설계14/13에 기록했다. 생성 세계는 초기 로스터 기반이며 계약/일정/경기·30개 공식 구단 메타데이터가 자동으로 준비됐다는 뜻은 아니다.
- us-inventory.ts는 실제3420명 등록과 조직별 점유를 읽고 신뢰된 세계/재무 작업자의 모집 정원·예산 할당을 연결한다. Rookie/A 모집 여유를 합쳐 조직160명을 넘지 않게 검사한다. 테스트의24/24정원·$5,000,000는 통제된 입력이며 게임 공통 경제 규칙으로 확정하지 않는다. 예산을 선수 강도에서 추정하지 않는다.
- 생성3420명→모집 재고→고교 미국 제안3개→수락→자리1개·계약금/연봉 예산 예약의 경로를 검사했다. 원본 학교 기록/18세 나이는 그대로다. 전체 미국 선수단에 주인공을 실제 배치하거나 경기를 치르는 단계는 후속이다.

## 계산 추출과 호환

KBO의 능력치 공통-offset 배분만 initial-abilities.ts로 옮겼다. kboInitialAbilities의35~85 입력 경계/공개 함수는 유지한다. 원래714개(14유형×51목표) 능력 배열 해시와 난이도별 KBO 세계 전체 해시3개를 추출 전후 비교해 모두 일치했다. [이전](evidence/M2-AF-kbo-before.json) · [이후](evidence/M2-AF-kbo-after.json) · [동일성](evidence/M2-AF-refactor.log).

US 초기 모델은 us-roster-1이며 기존 학교/KBO 저장값을 변경하지 않는다. 이미 생성한 US 세계를 조회/복원할 때 다시 생성하지 않는다. assertInitialUsRosterWorld는 고정 초기 인원 검사이므로 영입·승격·노화 뒤 일반 세계 검사로 재사용하지 않는다.
