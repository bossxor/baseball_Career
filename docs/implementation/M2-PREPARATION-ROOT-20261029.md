# 준비 시즌 루트 연결

`career-preparation.ts`가 `HighSchoolCareer`와 기존 준비 시즌 reducer를 연결한다. 실제 독립리그 216경기(주인공 팀 48경기), 일일 기록·건강, 연간 성장·노화 정산 뒤에만 평생 예산을 차감한다. 고교 E04는 참가 확정 시 닫고 이전 세계·성장·건강 원장과 지명 결과는 보관한다. 이후 KBO 평가는 해당 독립 시즌의 실제 성적 보정과 성장한 선수로 새 assessment를 만든다.

기존 9개 팀·선수 식별자·능력·구종을 재사용한다. 독립리그 전용 NPC 분포·추가 선수 생성 규칙은 정의하지 않았다. 부상으로 기존 선수만으로 합법 라인업을 만들 수 없으면 기존 엔진 오류를 유지한다. 독립리그 팀 재편·긴급 충원 정책은 별도 결정이 필요하다.

현재 루트는 실제 미지명 또는 지명 거절이 확인된 국내 아마추어를 대상으로 한다. 프로 방출·군복무·귀국 의무 준비의 전체 root 연결, 독립 시즌 이후 대학 입학·미국 진로·자유선수 시장 연결은 미완료다. 해당 진로 오퍼를 만들어 노출하지 않는다. 준비 시즌 훈련·유형·명단 변경은 `trainCareerPreparation`, `setCareerPreparationPlan`, `setCareerPreparationRosters`로 root 원장과 함께 갱신한다. `assertCareerPreparation`가 root의 세계·기록·성장·특성·관계·유형 사용 이력·진행 단계를 내부 준비 원장과 비교한다.

검증 대기: root 실제 48경기 테스트 및 stale/원본 보존 테스트 추가. 요청에 따라 개별 실행·전체 검사·Git 작업은 하지 않았다. 일괄 구현 완료 후 한 번의 전체 검사에서 확인한다.
