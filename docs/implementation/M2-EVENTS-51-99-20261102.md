## 필요한 연결과 최소 수정 경계

1. **E71 CHOOSE_FOCUS.** `careerRouteNoticesView`는 DOMAIN 선택을 광고하지만 `resolveCareerRouteNotice`는 DOMAIN을 거절한다. `setCollegePreseasonFocus`는 실제 활성화된 대학 PRE에만 존재하며 E71 receipt를 해결하지 않는다. 실제 admission/activation/preseason을 증명한 notice 전용 명령에서 기존 focus writer를 호출하고 성공 receipt로 E71만 닫아야 한다. PRE 전에는 실제 적용을 지연하거나 합법 시점에만 선택을 표시한다. ACK 테스트만으로 이 선택을 완료 처리하지 않는다.
2. **E73 OPEN_US_IF_VALID.** docs43의2학년 선택은 조기KBO/재학/실제US제안이며 US조회만으로 학적·기회를 소비하지 않는다. 지금 `prepareCareerUsDirect`는 이미 E73을 해결한 `CAREER_ROUTE`+`collegeEarlyRouteView`만 허용하므로, 열린 E73에 유효한 소유 quote가 도달하지 못한다.2학년 결과를 유지한 별도 owned quote 단계와 source-validating 탐색 명령을 두고, 실제 scout/slot/budget/유효 오퍼가 있는 경우만 S29를 열어야 한다. 탐색에서 `earlyDraftAttempted`를 바꾸거나 E73을 닫으면 안 된다. 실제 서명 때만 owned receipt로 E73·학적을 닫는다. 회귀는 유효오퍼·예산0/만료·CAS/위조·JSON·학적/기회/원본 불변을 검사한다.
3. **E74 REQUEST_RETIRE.** 실제 unsigned-return E74를 source/version 검증하고 사건을 연 채 S09로 탐색하는 handler가 없다. KBO/US 수동은퇴 owner는 pro root/닫힌 pro시즌을 요구하며 학교 root로 호출할 수 없다. 학교 수동 종료 확인/취소가 필요하면 별도 검증된 amateur receipt/기록보존 경계를 추가한다. 현재 E35는 lifetime3/실제 무경로 소진 전용이므로 수동 종료로 우회하지 않는다. 단순 S09 UI phase 변경을 실제 은퇴 archive로 세지 않는다.
4. **E85 프로 summary adapter.** 큐에 E85를 새로 만들 필요는 없지만, 현재 summary reader/ACK는 학교 root와 world.protagonistKey에 의존한다. 프로 root는 최상위 protagonistKey이며 기존 hidden E84 adapter만 있다. 일반 해금의 모아 읽기·cursor 갱신을 KBO/US 실제 원장 검증과 함께 연결하고 읽기가 경기/성장/정산 seal을 변경하지 않는지 검사해야 한다.
5. **E68 미지명 후 선택 준비.** 실제 원본·mandatory2년·미지명 receipt는 보존된다. 현재는 새 retry episode까지만 있고 native 선택형 준비/현재년도 재평가/US기회·E35의 후속 owner가 없다. 부모의 `2026-11-02-us-return-retry.md` 계획 범위와 중복되며 별도 발견으로 이중 계산하지 않는다.

E91–E93과 E54/E62는 실제 공개 엔진 명령을 호출하면 소스 조건·효과가 동작한다. 자동 게시/HTTP/화면 진입이 없는 것을 그 도메인 전체 부재로 쓰지 않는다. 반대로 “99사건 자동 도달 가능”을 선언하려면 이 명시 입구의 실제 호출층도 증명해야 한다. 외부 milestone 생산자와 위5개 M2 연결을 구분하며, 이 문서는 새 전체 검사 또는 M2 완료 선언이 아니다.
