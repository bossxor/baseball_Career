# M2-E 보유 특성의 실제 경기 효과

2026-10-20. 47/56/100/107의 조건별 효과와 기본 해금 계산을 구현했다. 전체 기록 원장·관계/연속시즌 evidence 생성과 DB transaction은 후속 작업이다.

## 적용

- 보유 특성은 장착 제한 없이 타석 시작마다 firstMeeting/만루/PS/이닝/자기팀 리드/선발/본인실점/T14의 확정 대상 집합을 검사한다. 첫 대면은 확정 play log의 상대 쌍 방문 여부이며 BB/HBP도 소모한다.
- T03은 주자 snapshot에 보존된 추가진루+.02, T04는 일시수비 clamp 이후·피로/사기/적합도 전에+2, T10은 실제 선발의 교체 검토 구수+3/105 cap이다. 비logit 효과는 logit cap에 섞지 않는다.
- 양쪽 보유 효과를 모아 기존 특성±.06→구종/성향/폼/좌우 포함±.10 cap 순서를 유지한다. T14는 이미 증명된 상대에게만 적용한다.
- 12개 공개/4개 히든 해금 조건은 정규/커리어 증거와 영구 능력으로 계산하며 기존 보유 및 T14 대상은 정정/노쇠에도 박탈하지 않는다. 같은 대회 정규 증거끼리 호출해야 하며 다른 리그 PA와 장타를 섞으면 안 된다.
- T14 OPS는 BigInt 원분모로 .900을 비교하고 관계 WIN·PA20·AB>0을 모두 요구한다. 실제 라이벌 관계 형성/결투/완봉/T16 연속 시즌 원장 생성은 아직 연결 전이다.
- 미해금 히든 카드 투영은 traitId/hidden/name/hint만 반환한다. 웹 소스의 engine/API/DB 직접 import를 린트에서 금지하여 서버 특성 규칙을 클라이언트 번들로 가져오는 경계를 막았다. 실제 API 권한/캐시 검증은 M3/M4다.

## 엔진 호환

새 게임의 traitRulesVersion=1은 engineVersion1.1.0으로 실행한다. 입력 소유 특성과 사전계산 traitLogits 혼합은 거절한다. 구버전 게임 입력은1.0.0 경로 그대로 재개하며 고정 M1 SHA256은 유지했다. ENGINE_VERSION은 최신1.1.0, LEGACY_ENGINE_VERSION은1.0.0이다. 없는 기능을 과거 경기 결과에 소급하지 않는다.

## 검증

집중9/9·전체121/121·lint/typecheck/build/빌드M1골든/설계10종 통과. 실제 특성 경기와 매타석 JSON 저장/재개 결과가 일치한다. 특성이 없는1.1과1.0의 확률·난수·점수·투수판정도 동일하다. runner 본인의T03 유지, 조건 경계, 기본 해금 중복0/보유유지, 숨김카드 allowlist, 수비 임시감소/100상한을 확인했다. 첫 집중검사에서 기존 combineEffects 반환 필드를 잘못 참조한 테스트1개는 실제 반환 필드로 수정했다.
