# M2-BQ — AI 재계약·만료 FA 이동 준비

2026-10-22. 다음 시즌을 준비하는 내부 순수 reducer다. 아직 startNextKboSeason의 임시 자동 재계약을 교체하지 않았으며, FA시장/최종편성까지 검증한 뒤 원자 연결해야 한다.

## 판단과 보존

prepareKboAiRenewals는 실제 만료 NPC만 비교하고 다년 보장/내 수락계약은 그대로 둔다. 기존 초기50명 목표(D)까지44의 필요자리100 우선·roleScore 개선·전망중앙·연봉비용으로 재계약하며08의1년 연봉식을 쓴다. 예산/35명 보호액을 검사하고 실패한 제안을 몰래 체결하지 않는다. 남은 NPC는 FA로 이동해 ID/A/P/최고값/구종·이전계약을 보존한다. 기록을 삭제하지 않는다. 보장계약이 이미50명을 넘으면 강제로 방출하지 않는다.

AI 평가 보고서는67의 고정 범위·초기시설2·실제 등록 정규 관측을 사용한다. 같은 세계의 실제 KBO/FUTURES 게임·건강팀 receipt만 관측하고,20회마다stage 최대4다. 무등록 날짜·조회로 관측을 늘리지 않는다. 의사결정 함수는 rawP를 받지 않고 공개 전망 중앙값을 받는다. 자료가 없는 선수의 직접 P 비교로 대체하지 않는다.

만료 선수가 부상 중이면 injury를 FA 프로필로 옮기고 live health에서 해당 미등록 key를 제거한다. 경기 작업자에게 유령 부상 key를 넘기지 않으며 새 계약 때 잔여 경기수를 복원할 수 있다. 무등록 치료 팀경기는0, 재활 연말 성장·중대부상 마감은 기존 규칙과14의 D다. 공개 FA 목록은 부상이 있으면 severity/잔여경기만 추가한다.
