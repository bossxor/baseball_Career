# M2-L 생성 고교 세계와 실제 경기 연결

2026-10-20. 고교9팀/225명 생성 결과를 실제 결정론1.2 경기와 FINAL 기록·구종 원장에 연결했다.

- 일정의 원정/홈 순서·세계/시즌/일자를 사용한다. 같은 팀 중복선수·누락 신원·부적격 선발·미등록 가용성·없는 구종 book을 거절한다. 자동 수비 배치로9명을 선정하고 좌투 제한을 유지한다.
- 선발 선택/최근 기록/가용성은 상위 서버 세계 AI가 먼저 확정해 전달한다. 다른 로테이션 SP는 그 경기 불펜으로 자동 소비하지 않는다. 상태·기록·book을 직접 웹에서 받아서 실행하는 API가 아니다.
- 고유 특성·타격 접근·피로·투타/폼·활성 구종/숙련을 불변 snapshot으로 만든다. 커리어 치트 구종XP3배는 내 선수에만, 하드 NPC1.2배는 상대 NPC에 적용한다. 전체 상대 잠재력을100으로 바꾸지 않는다.
- pending job은 세계 논리키/시즌/날짜·세계 원본 canonical snapshot·기록 revision·게임과 stopReason을 보존한다. 타석 단위 JSON재개와 ENGINE_LIMIT 전달을 지원한다.
- FINAL에서만 공식 기여와 각 투수 book을 하나의 새 결과로 반환한다. 원본 상태는 불변이다. 세계 snapshot 또는 기록 revision이 바뀌면 거절한다. 같은 확정 경기 재처리는 기록/숙련을 더하지 않는다. M3가 두 결과와 receipt를 한 DB transaction으로 저장해야 한다.

집중5/5·전체166/166, lint/typecheck/build/M1 골든/사건 동기화/설계 정적10종 통과. 첫 고교 경기 실제 진행, JSON 중간재개/연속진행 동일, 공식 기록/XP 게시1회, 낡은 근거 거절, 부상 가용성, 첫날4경기/8팀/1팀휴식 확인. 최초 테스트는 원장 속성명 오기로 실패했고 actualBudgetSpentUnits로 수정 후 통과했다.

미완료: 실제 커리어 명령/phase·고교 전체48경기 경로·일별 피로와 부상 hook·임시 NPC 생성/등록·관측/특성/목표/사건·졸업 진로/오퍼·인증/저장/UI. world.phase=CREATED는 생성 결과의 표식이며 이 adapter가 그 phase를 경기 진행 승인으로 해석하지 않는다. 상위 커리어 명령이 먼저 phase/queue/등록/날짜를 검증해야 한다. 현재 경기 adapter 검증을 커리어 시즌 완주로 보고하지 않는다.
