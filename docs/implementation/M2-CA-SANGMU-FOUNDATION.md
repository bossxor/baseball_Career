# M2-CA — 상무 포함 퓨처스 11팀 일정·상무 연간 선발 (순수 기반, 미활성화)

2026-10-22. 사용자 확정(14 U, M2-BY)의 첫 구현 조각이다. 둘 다 순수 함수이며 **세계·일정에 연결하지 않았다**(기존 10팀 퓨처스 저장 일정/기록 불변, 상무 팀 없음, 병역 상태/계약 정지/복귀 미구현).

## 1. 11팀 퓨처스 일정 (`createKboFutures11Schedule`, kbo-futures-schedule.ts)

- 11팀·팀당 144경기·홈 72/원정 72, 상대 14경기 또는 15경기(상대 10팀 중 4팀 15·6팀 14).
- 구성: 11팀 1회전×14번(쌍당 14경기, 홈 7/7 대칭) + 추가 22경기. 추가 쌍은 시즌 stride(1+연도%10, 서로 다른 5개 그래프)로 순열한 팀 순서 위의 C11(1,2) 순환 그래프이고 i→i+1·i→i+2를 홈으로 지정해 팀마다 추가 홈2·원정2. 추가 경기는 같은 날 겹치지 않게 선착순으로 경기일에 채우고 전체 라운드를 달력 성장일에 순서대로 펼친다. `assertSchedule`(중복 예약·144/72·연속 6일 초과 금지)을 통과해야 반환한다.
- 라운드 수는 154 + 추가 라운드(성장일 수 이상이어야 하며 부족하면 실패). 기존 `createKboSeasonSchedules`(10팀)는 그대로다.

## 2. 상무 연간 선발 (`selectSangmuCohort`, kbo-sangmu.ts)

- 21 §상무 선발: 야수 10·투수 10(사용자 확정), 게임나이 19~27, 건강한 선수만, 점수 = .6×roleScore + .4×최근2시즌 성적지수(KBO+퓨처스 정규 기록 합산, 표본 부족은 공용 지수의 50). 동률은 젊은 나이→안정 seed 해시→ID. 이미 복무 중인 선수와 내 선수(`excluded`, 사용자 지원 경로)는 제외. 지원자가 부족하면 공석으로 남기며 선수를 만들지 않는다.
- **구현 기본값 D(사용자 세부 배분 대기)**: 10명 기준 역할 세부 배분이 아직 없어 야수 최소 포수 1·투수 최소 선발 3만 보장하고 나머지는 점수 순이다. 21의 종전 5명 기준 배분(C1/내야2/외야2·SP2/RP2/CP1)은 쓰지 않는다.
- 스냅샷 키 `["sangmu-selection", worldKey, seasonKey]`로 고정해 재호출이 같은 결과다.
