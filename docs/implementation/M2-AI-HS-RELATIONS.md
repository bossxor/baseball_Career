# M2-AI — 고교 라이벌·동료 관계 형성과 목록 투영

2026-10-21. [60](../design/60-RELATIONS-DETAILED-CONTRACT.md)·[51](../design/51-RIVALS-TEAMMATES.md)의 고교 시작 관계 형성을 커리어 시작(`confirmCareerPlayer`)에 연결했다. 새 게임 규칙은 추가하지 않았다.

- 동료 1명: 내 고교 실제 명단에서 같은 종류, 나이 차가 작은 순→ID 순의 첫 선수. 없으면 `NO_CANDIDATE`.
- 라이벌 1명: 같은 종류·나이 차 1 이하·영구 종합 차 5 이하(6능력 합 300,000 units 이하, 표시 반올림 대신 정확 정수 비교)·자기 제외·동료와 다른 ID. 같은 고교도 가능하다. 후보를 ID로 정렬한 뒤 별도 `relation-formation` 난수 스트림에서 하나를 고른다. 경기·건강·평가 난수는 쓰지 않는다.
- 관계는 정렬 ID 쌍 키·종류·단계 FORMED·형성 이정표로 저장한다. 같은 상대가 두 역할을 받지 않는다.
- `relationshipListView`(S42 목록): 상대의 이름·종류·포지션·던지는 손·타석·투구폼·학교명만 내보낸다. 능력·잠재력·seed는 넣지 않는다. 현재 세계에 없는 상대(진학 후 다른 세계)는 저장은 유지하고 목록에서만 빠진다.

## 설계와 다른 점(후속)

- 60은 라이벌 후보가 0명이면 51의 고교 선수 생성 루틴으로 1명을 추가하라고 한다. 이번에는 생성하지 않고 `NO_CANDIDATE`로 기록한다. 세계 인원 상한·로스터·드래프트 풀까지 함께 바꿔야 하므로 별도 단계로 남긴다. 현재 고교 세계는 학교마다 같은 종류 선수가 많아 후보 0명은 드물다.
- SEPARATED/REUNITED_*/RETIRED 전이, 맞대결·비교 기록 집계, E94~E96 사건, 프로 cross-kind 관계(T14 근거)는 아직 연결하지 않았다.
