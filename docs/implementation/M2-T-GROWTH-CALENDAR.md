# M2-T — 실제 성장 달력과 고교 기간 정산

2026-10-20. 사용자가 세계 2~10월·고교 2~6월·주간 휴식 포함·국제창 제외 기본안을 승인했다. 날짜 기본값과 이전 압축 일정 보존 정책은 [14](../design/14-CANONICAL-DECISIONS.md)에 기록했다.

## 구현 범위

- `createSeasonCalendar(year)`는 시간 API 없이 윤년과20의 개최 주기를 계산한다. `calendar-1`의 날짜 집합과 국제창을 세계에 저장하고 복원 시 정의와 대조한다.
- 새 세계 생성은 `seasonYear`를 받으면 고교54라운드/216경기/팀48경기/홈24경기를 2~6월에 배치한다. 기존 `startDay` 방식의 압축 일정은 변경하지 않는다. 두 입력이 충돌하면 거절한다.
- `collectHighSchoolGrowthEvidence`는 모든 날짜 마감과 FINAL 기록, 실제 팀 등록·건강 근거를 확인한다. 타자는PA, 투수는아웃을 집계하고 주간 휴식·부전일도 보존한다. 부상 진단 다음 날부터 복귀 경기일까지 재활로 계산한다.
- 계획의0/12/24 팀경기 경계는 확정 경기의 다음 날짜부터 적용한다. 수집은 원본·revision·난수를 변경하지 않는다. 시즌시작 능력은 강화 전 snapshot을 사용한다. 해당 snapshot이 없는 이전 세이브에는 현재 능력으로 가짜 원본을 만들지 않는다.
- `settleHighSchoolCareerGrowth(career, expectedRevision)`는 SEASON_REVIEW에서 실제 달력을 세계 성장 인덱스로 바꾼 뒤 M2-I 공유 원장에 부분 지급한다. 기간별 집중·유형·출장·재활 비율과 저장된 난이도를 사용한다. 강화는 재가산하지 않고, 반복 지급은0이며 원장은 후속 등록기간을 위해 열린 상태로 둔다. 진로·오퍼 생성과 노쇠/연말 마감은 이 명령에 포함하지 않는다.

## 수치 충돌

대표연도 W/D: 2029=273/150,2030(WBC+AG)=238/129,2031(P12)=273/150,2032(윤년+OLY)=260/151. 이전의 W=D=100 계산 fixture는 실제 세계 달력의 도달성을 입증하지 않는다.

현재18세 연간 총합 예산10·일반1.5배/하드1배·영구 강화 최대+2를 유지하면 이 네 연도에서 출장계수1.1·정상 훈련의 이상적 상한도 졸업 종합52 미만이다. 따라서 일반/하드의 첫 고교 졸업 직후 미국 경로는 현재 규칙에서 도달 불가능하다. 문턱52·배율·추가 성장은 임의 변경하지 않았다. 미국 고교 직행을 실현하려면 별도 승인된 밸런스 조정이 필요하다. 대학 이후 미국 진로의 도달성은 이번 검증 범위가 아니다.
