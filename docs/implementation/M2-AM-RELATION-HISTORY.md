# M2-AM — 과거 관계 목록과 상세 조회

2026-10-21. 대학 진입 후 현재 선수단에서 사라진 고교 관계도 previousSeasons의 같은 세계/seed 신원으로 조회한다. 현재 신원을 우선하고 없으면 최근 과거 등록을 보여준다. 실제 등록/진로 근거 없이 분리·재회·은퇴 상태를 만들지 않는다.

careerRelationshipListView/careerRelationDetailView는 공개 신원과 마지막 확인 등록만 제공한다. 숨김 잠재력·능력·seed를 내보내지 않으며 기록 조회는 기존 리그/시즌/단계 필터를 사용한다. 누락된 과거 참조는 UNKNOWN_REFERENCE로 남긴다. E94도 보관된 이름을 사용하며 새 사건으로 재생성하지 않는다. 기존 현재 세계 전용 조회 API는 유지한다.

## 검증

관련21/21(34.70초), 타입·lint·전체 build·compiled M1 골든·이벤트 동기화·설계 정적10종·HTTP smoke 통과. evidence/M2-AM-* 로그를 따른다. 첫 타입 검사는 테스트의 불완전 BattingTotals로 실패했으며 모든 필드를 갖춘 fixture로 수정한 뒤 통과했다. 전체 장기 시즌 묶음과 브라우저/DB는 이번 단계에서 실행하지 않았다.
