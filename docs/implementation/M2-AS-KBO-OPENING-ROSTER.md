# M2-AS — KBO 개막1군/퓨처스 명단

2026-10-21. 확정 프리시즌 계획 다음에 실제 구단 명단에서 개막1군28명과 나머지 퓨처스 명단을 결정한다. 첫 경기/타순/등판은 별도이며 경기 일정은 아직 없다.

## 기존 규칙 재사용

초기 KBO 세계의 private firstTeam 함수를 selectKboFirstTeamRoster로 공개해 같은41/44 편성 알고리즘을 사용한다. 8수비+DH 실제 배치, 포수2명 이상·야수15/투수13·SP5/RP6/CP2를 유지한다. 이전 시즌 표본이 없는 개막 편성 전용이며 시즌 중 실제 최근 성적을 무시하는 콜업 알고리즘으로 재사용하지 않는다.

새 추첨/능력 문턱/성장 보너스는 없다. 포지션 수요에 따라 평균적인 신인도1군에 들 수 있고 강한 경쟁군이면 퓨처스에 남는다. 부상자는1군 후보에서 제외하고 남은 회복 팀경기를 줄이지 않는다. 1군 슬롯을 확보해도 실제 타순/출장이 보장되지 않으며 아직 FUTURES 경기 등록 이력이 없으므로 첫 호출 E09를 임의 발행하지 않는다.

## 원자 전환·조회

confirmKboOpeningRoster는 확정 계획/버전과 유효한 계약/선수단을 검사한다. 실제 선택을 모두 검증한 뒤 대상 구단의 firstTeam·내 registration.firstTeam/competitionKey·명단 영수증만 한 결과로 확정한다. 다른 구단, NPC/내 선수 능력·P/나이, 계약/자리·연봉 예약, 기록/건강·성장/구종·관계/학교 원본을 바꾸지 않는다.

대상 구단51명 중1군28·나머지23명을 겹침 없이 보존한다. 인원/포수/수비 부족이면 명시적으로 실패하며 무료 선수 생성/강제 치료/부분 명단 저장은 없다. 같은 원본/JSON 재실행은 같은 결과이고 같은 확정 상태 재요청은 중복 반영하지 않는다. 메타데이터 읽음 후에도 영수증의 본래 확정 revision/근거가 유지된다.

kboOpeningRosterView는 확정 전 PENDING을 읽으며 조회만으로 선발하지 않는다. 확정 후 실제 KBO/FUTURES와 명단의 신원/포지션·부상/경쟁 사유만 제공한다. P/RNG/능력·사적 근거·가짜 선발확률을 노출하지 않는다. firstTeam:true인 새 저장값을 기존 프로 신인 조회/프리시즌·관계 reader도 올바르게 읽는다.

## 검증

- 초기 KBO6/6 기준 통과. 세 난이도의 같은 입력 세계 SHA256을 변경 전후 비교해 모두 일치했다. 첫 편성 함수를 공개한 것 외에 기존 생성 알고리즘·분포/금액은 바꾸지 않았다. [전](evidence/M2-AS-world-before.json)·[후](evidence/M2-AS-world-after.json).
- 최종40/40(29.66초): 개막 명단9개와 기존 세계·프로 등록/계획/관계 회귀. 강한 타자/투수의 실제 서명→등록→계획→1군28, 평균50 시작의 실제 계약/포지션 수요, 통제된 강한 경쟁군에서 퓨처스, 부상/포수 부족 안전 실패, 중복/JSON·버전/위조, 알림 읽음 뒤 두 계획 보존을 확인했다. 강한 경쟁군/포수 부족은 명시적 통제 fixture이며 생산 NPC 분포나 실제 부상 경기 실측이 아니다.
- 첫 집중38/39 중 평균50 선수를 무조건2군으로 가정한 테스트1개가 실패했다. 실제 목적 구단의 포지션 수요로1군에 드는 기존 규칙이 맞아 테스트 기대를 고쳤다. 강한 경쟁군의 별도 fixture로 퓨처스 분기도 검증했다. 이를 위해 게임에 임의 문턱/버프를 추가하지 않았다.
- 최종 소스/테스트 타입·lint·전체 build·compiled M1 골든·이벤트 동기화·설계 정적10종·HTTP smoke 통과. evidence/M2-AS-* 참조. 전체337/337은 이전 M2-AO 기준이며 AS 뒤 전체 묶음을 재실행한 것으로 보고하지 않는다.

## 호환·다음

openingRoster/registration.competitionKey가 없는 기존 AP/AQ/AR 저장값은 미확정 상태로 읽는다. firstTeam은 이제 실제 명단을 반영하는 boolean이며 기존 false 저장값은 유지한다. 새 writer를 켜기 전에 이 reader를 배포하며 롤백 시 writer만 중단하고 새 명단/1군 flag reader를 유지한다. 영수증을 지우거나1군 flag를 false로 되돌려 재선발하지 않는다. 실제 저장자는 revision/영수증을 단일 원자 쓰기로 보존해야 한다. DB 작업자는 아직 없다.

현재 PRESEASON_SETUP에서만 개막 원본 검증을 사용한다. 실제 시즌 진행으로 피로/능력/등록이 변하면 개막 영수증은 원래의 역사로 보존하고 현재 상태에 다시 대조하거나 개막 선발을 다시 실행하지 않는다. 다음은 실제1군/퓨처스 달력·일정/라인업/경기와 슬롯별 기용·콜업/강등, 성향/포지션 전환·정규 강화다. 실제 플레이 UI/API/계정·Neon·APK는 후속이다.
