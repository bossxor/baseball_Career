# M2-U — 고교 결산·E04 진로·대학 입학 확정

2026-10-20. M2-T의 실제 고교 기간 성장을 결산 확인 명령에 연결하고, 기존19/34/43/125의 진로·입학·필수 사건 계약을 구현했다. 새 성장 배율이나 미국 문턱 변경은 없다.

## 구현한 경로

`SEASON_REVIEW → acknowledgeHighSchoolSeasonReview → EVENT_DECISION(E04) → openHighSchoolCareerRoute(S28) → CAREER_ROUTE → enrollHighSchoolCollege → NEXT_SEASON_READY`

- 결산 확인은 M2-T 성장 정산과 E04 생성, 성장 후 진로 평가 snapshot을 하나의 불변 reducer로 반환한다. revision은 한 번만 증가하며 검증 실패 시 성장/사건을 일부만 게시하지 않는다. 기존에 지급한 고교 성장은 재가산하지 않는다.
- E04의 OPEN_ROUTE는 화면 이동이다. 조회/이동으로 사건을 해결하지 않으며, 실제 입학 결정이 커밋되어야 `completeBlockingEvent`로 닫는다. 해결된 E04도 같은 근거로 재생성하지 않는다.
- rules의 대학9곳은43의 학교명·특징·최소종합·주전 평가선을 사용한다. 입학 문턱48/52/55는 표시 반올림 전 종합으로 비교한다. 하위3곳은 최소종합1이며 단순 입학 동작에 확률 배지를 만들지 않는다. 주전 평가선은 출장 보장이 아니다.
- 공개 진로 투영은 명시한 필드만 반환한다. 숨김 잠재력·seed·RNG·성장 원본·서버 평가 근거를 보내지 않는다. 반복 조회와 JSON 복원은 성장/난수/revision을 바꾸지 않는다.
- 입학 명령은 save revision·E04 version·offerSetKey/version·현재 평가 근거·학교 자격을 다시 검사한다. 입학 영수증과 다음 시즌의 학교/포지션/학년1/완료학년0을 저장한다. 같은 입학을 두 번 확정하거나 다른 대학으로 바꾸지 못한다.
- 상태 `ADMITTED`는 다음 시즌 입학 결정이다. 예를 들어2032년 고교 결산 뒤 입학은2033년 효력이며, 선수는 아직18세다. 나이 증가·실제 대학 로스터 등록·학년 진행은 후속 세계 연도 전환에서 한다. 완료된 고교 세계/명단/공식 기록은 역사 자료로 보존하므로 현재 고교와 대학의 동시 활동 등록을 생성하지 않는다.

## 명확한 미구현 범위

- KBO 세계·구단별 실제 모집 슬롯/수요가 아직 없다. 진로 투영은 `AWAITING_RECRUITMENT`를 반환하며 임의 지명률·구단·라운드·계약을 만들지 않는다. KBO 참가 확정과 실제 추첨은 모집 세계를 연결한 뒤 구현한다.
- 실제 유효 미국 오퍼 생성기가 없으므로 미국 진로 카드를 반환하지 않는다. 일반/하드 첫 졸업의 종합52 도달성 충돌은 유지하며 별도 밸런스 결정이 필요하다. 이 문제로 독립적인 국내·대학 구현을 막지 않는다.
- 대학 다음 시즌의 세계/로스터 생성·학년 경기·선수권, NPC 진로 배정·연간 성장, 계약·병역, API/DB/웹UI는 미구현이다. 이번 입학 결정이 대학 시즌 플레이 완료를 의미하지 않는다.
