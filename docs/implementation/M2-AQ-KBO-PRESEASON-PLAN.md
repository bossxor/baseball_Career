# M2-AQ — 프로 첫 캠프와 프리시즌 계획

2026-10-21. KboCareer의 실제 프로 등록 다음에 프리시즌 집중/유형/구종·학습과 계획 확정을 연결한다. 근거는22/35/57/101과 기존 E08이며 새로운 성장 수식이나 경기 보너스는 없다.

## 동작

- E08 첫 캠프는 별도 campNotices의 비차단 NOTICE다. 새 등록에서1회 생성하고 이전 AP 저장값은 읽기 때 생성하지 않으며 첫 쓰기에서 보충한다. 현재 집중 유지 ACK는 새 계획을 만들지 않고, 집중 선택 DOMAIN은 유효한4개를 실제 저장한 뒤만 닫는다. 타입/이벤트 버전·원본 등록 근거를 검증한다.
- 집중은 서로 다른 같은 선수 종류의4능력이다. 유형은 기존 PRE1회 규칙을 공유하고 같은 유형은 횟수를 소모하지 않는다. 유형/집중으로 영구 능력·P·성적·난수를 바꾸지 않는다.
- 구종 비율은 기존 setPitchWeights를 사용한다. 학습은 beginPitchLearning으로 기본XP10 예약/미보유 구종/4슬롯 교체·PRE 구성 변경 동시 소모를 지킨다. 새 학습의 숙련은0이며 성장3배/분기 정산은 기존 별도 XP 작업자를 따른다. 클라이언트가 임의 windowId/치트/분기 지급값을 넘기는 명령은 없다.
- confirmKboPreseasonPlan은 선택한 계획을 growth/development 시즌 시작 스냅샷에 반영하고 영수증으로 확정한다. 새 경기/등록/성장 지급을 만들지 않고 phase는 PRESEASON_SETUP이다. 이후 roster/schedule 활성화가 실제 시즌을 시작해야 한다.
- E08을 읽지 않아도 계획을 확정할 수 있다. 확정 뒤 카드는 KEEP_FOCUS만 허용하며 낡은 클라이언트의 CHOOSE_FOCUS 요청도 거절한다. 읽음 revision 변경은 계획 근거를 손상시키지 않는다.
- kboPreseasonPlanView와 unreadKboFirstCampNotices는 명시적 공개 DTO다. 숨김 P/RNG/과거 원본/사적 sourceBasis는 내보내지 않는다. 구종 학습 가능 여부는 잔여 예산/미보유 구종/가용 슬롯 또는 교체 기회까지 검사한다. 단순 설정 확률 배지는 없다.

## 호환·롤백

campNotices/preseasonPlan이 없는 AP 저장값은 미확정 계획/읽지 않은 캠프 없음으로 읽는다. 새 필드는 선택적이며 세계/학교 원본을 재생성하지 않는다. 캠프 알림과 확정 계획을 저장한 후에는 reader를 유지하고 writer만 중단하는 롤백을 사용한다. 이미 확정한 계획·PRE 소모·학습 예약을 삭제해 기회를 다시 열지 않는다. schemaVersion1을 유지하며 기존 학교 revision 검사는 최소 메타데이터 타입만 받도록 넓혔고 동작은 바꾸지 않았다. 실제 DB/API 마이그레이션은 없다.
