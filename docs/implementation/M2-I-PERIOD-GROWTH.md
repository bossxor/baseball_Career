# M2-I 고교 졸업 전 부분 성장·세계시즌 공통 지급 원장

2026-10-20. 사용자 승인 고교 성장 시점과22/42의 기간별 계획·연간 중복방지를 연결했다.

- 시즌 시작 나이/선수 snapshot·고정 worldGrowthDays·논리 선수키를 원장에 보존한다. 등록기간을 닫아야 지급할 수 있고 중간 focus/유형 변경 전후를 각 역사 snapshot으로 배분한다. 과거 배분을 계산해도 현재 사용자가 고른 계획을 덮어쓰지 않는다.
- 누적 기간 예산을 먼저1e-4 반올림하고 이전 지급 예산을 뺀다. 여러 부분 정산의 합은 같은 기간을 일괄 처리한 합과 같으며 기간별 반올림으로 예산을 복제하지 않는다.
- 매 기간 budget=gained+discarded,6능력 증가합=gained를 보존한다. 잠재력 상한으로 소멸한 예산도 처리 완료로 남아 다음 리그에서 되살아나지 않는다. 같은 기간키 재처리0,근거 변경·겹침·과거 기간 삽입·원장 합계 손상은 거절한다.
- 성장과 노쇠를 분리한다. 최종 노쇠는 실제 경과 성장달력 일수 비율로 한 번만 적용하며 치트3배로 늘리지 않는다. 현재 능력 하한·커리어 최고값 보존. 일반 현역의 성장0 기간도 달력상 노쇠를 없애는 근거가 아니다.
- period.startDay/endDay는 세계 성장가능일 인덱스[0,W]의 반개구간이다. 화면/일정의 절대 worldDay를 변환 없이 넣지 않는다. 공식 달력/등록·관측/출장·재활 근거와 닫힌 계획 구간은 상위 커리어 진행 처리에서 만들어야 한다.
