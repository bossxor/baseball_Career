- 잠재력: 고정 player/ability/model 키에서 z를 파생하며 진행 중인 세계 RNG를 소비하지 않는다. 능력별 범위는 기존 보고와 교집합으로 단조 축소하고 진짜P를 포함한다. A99/100은 물리적 범위로 처리하며 불일치는 안전 오류다. 내부1e-4 정수·표시는 바깥 반올림한다.
