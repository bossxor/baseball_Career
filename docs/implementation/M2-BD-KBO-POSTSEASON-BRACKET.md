# M2-BD — KBO 포스트시즌 대진·시리즈 상태(순수 로직)

2026-10-21. 01의 포스트시즌 독자 규칙을 순수 상태 기계 `kbo-postseason.ts`로 구현했다. 실제 경기 진행·기록·정지 연결은 다음 단계다.

- 시드는 정규 시즌 최종 1~5위(leagueStandings). 와일드카드 4위 vs 5위(2선승, 4위 1승 선취), 승자 vs 3위(3전2선승), 승자 vs 2위(5전3선승), 승자 vs 1위(7전4선승). 무승부는 없다(포스트시즌은 엔진의 10회 승부치기로 승자를 낸다).
- 홈: 상위 시드 먼저. 5전은 2-2-1, 7전은 2-2-3(01). 01에 없는 3전은 2-1, 와일드카드는 전 경기 상위 시드 홈으로 둔다(설계 기본안 D, 실제 KBO 규정이라고 표시하지 않음).
- `createKboPostseason`/`nextKboPostseasonGame`/`recordKboPostseasonGame`: 다음 경기(라운드·경기 번호·홈/원정)를 돌려주고 결과를 한 경기씩 기록한다. 시리즈가 끝나면 다음 라운드를 연다. 우승 확정 후 기록·잘못된 승자·잘못된 시드는 거절한다.

검증: 3/3(4위 선취와 단판 종료·5위 2승 업셋·홈, 3/5/7전 홈 패턴과 단일 우승팀·완료 후 거절, 잘못된 시드·승자 거절), lint·타입·build·M1 골든 통과. 순수 신규 모듈이라 이번에는 전체 npm run check를 다시 돌리지 않았다. [집중](evidence/M2-BD-focused.log).
