# M2 일괄 구현 — 대표 부상 긴급 후보 합류

2026-10-28. 구현 배치이며 실행 검증 완료 기록이 아니다. 사용자 요청대로 전체 `npm run check`와 집중 경기 시뮬레이션은 실행하지 않고 아래 검증 목록을 PENDING으로 모았다.

## 승인과 범위

20 §3~5/8, 14와 EH의 기존 첫 한국 경기 전/라운드 경계 규칙을 사용한다. 추가 동률 정책은 사용자가 **“긴급 후보끼리만 기존 시드 기반 추첨 적용”**으로 확정했다. 원래 점수/추첨순위는 유지하고 별도 `national-emergency-lots` 문맥의 배치 추첨만 기존 Fisher–Yates/RNG 함수로 수행한다. 새 점수 계수/표본 기준/능력 생성 정책은 없다.

`national-progress.ts`의 EH 교체 호출은 현재 같은 KBO 세계/시즌의 `kboNationalCandidates`를 넘긴다. 기존 봉인 후보로 공석을 먼저 충원한다. 같은 역할의 건강한 봉인 후보가 없을 때만 미평가 하위리그 후보를 실제 현재 선수에서 추려 기존 평가 산식으로 평가한다. 국적 KOR, 건강/은퇴/차출 허가/현역/상무 제한을 기존 자격 함수로 재검사하며, 이 긴급 경로만 하위리그의 최근 1군 기록 요건을 면제한다. 상무는 기존 AG 허용/다른 대회 제외를 유지한다. 없는 선수/한국 스타/능력/잠재력은 만들지 않는다.

미국 NPC는 입력하지 않는다. 신규 헬퍼는 국적 기본값을 만들지 않으며 명시된 `NationalCandidate.nationalTeamId`를 검사한다. 기존 KBO 전용 어댑터의 레거시 한국인 기본값은 기존 동작 그대로이고 미국 공통 후보풀의 국적 정책으로 전용하지 않는다. 미국 공통 후보/일정 통합은 별도 잔여다.

## 저장과 보존

선발 스냅샷에 선택적 `emergencyAdmissions`를 추가했다. 각 배치는 `beforeReplacement`, 평가 원장 `sourceRecordRevision`, 새 후보 `playerKeys`를 남긴다. 기존 `scores` 행과 lotRank는 그대로 두고 새 평가만 배열 뒤에 붙인다. 새 순위는 이전 최대 lotRank 뒤에서 시작하므로 원래 순위와 겹치지 않는다. 이미 평가한 긴급 후보는 다음 부상에서 다시 평가/추첨하지 않는다.

검증기는 최초 점수만으로 최초28명을 재생한 뒤, 해당 부상 교체 직전에 그 배치만 합류시켜 교체 순서를 재생한다. 기존 봉인 후보가 아직 있는 상황의 긴급 합류, DECLINED로 위장한 합류, 순위 재사용, 잘못된 시점/원장 revision은 거부한다. `emergencyAdmissions`가 없는 기존 저장은 종전 재생과 초기 RNG 문맥을 유지한다. 공개 선발 조회의 roster/protagonist에 `emergency:boolean`을 추가해 실제 긴급 승격된 선수를 표시할 수 있다. 평가만 받았고 실제 교체로 등록되지 않은 후보는 긴급 초청으로 표시하지 않는다.

명단 변경은 순수 값으로 준비한 뒤 실제 경기 준비 성공 시에만 커리어에 반영한다. 충원 실패면 원본/선수/기록/명단/대진/pending 불변이다. 기존 EH 경계와 pendingGame 거부를 유지하므로 준비된 경기·과거 경기/출장/라운드/건강 일영수증을 재작성하지 않는다. 이 문서가 이전 실제 출장·혜택 전체 경로의 신규 실행 증거를 뜻하지 않는다.
