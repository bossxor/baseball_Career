# M2-CT — 실제 이적의 같은 팀 재회 E96

2026-10-23. 설계60의 같은 팀 재등록/E96을 기존 시즌 중 잔여 계약 이적에 연결한다. 원구단 관계 분리 뒤, 목적지에 실제 등록된 SEPARATED/REUNITED_OPPONENT 관계만 REUNITED_TEAM으로 옮기고 E96을 발행한다. 부상만으로 등록 관계를 제외하지 않으며 군팀 대여·현역 계약 정지는 제외한다. 관계 종류와 이전 이정표·맞대결 기록을 보존한다. 라이벌은 RIVAL을 유지하고 별도 TEAMMATE 형성 E94와 공존할 수 있다.

이적 복제본 안에서 등록 근거·관계·사건을 함께 확정한다. 실패하면 원본 불변이다. 새 이적 영수증의 선택 필드 sharedRelationKeys에 그 시점의 재회 관계키를 봉인한다. 사건의 sharedTeamRegistrationReceiptId는 해당 이적/관계에 결합된다. 현재 명단으로 과거 재회를 추측하지 않는다. 나중에 소속이 바뀌어도 이 근거를 읽으며 누락/중복/잘못된 근거는 거절한다.

## 읽기·저장 호환

E94/E95/E96는 비차단 NOTICE이며 OPEN_RELATIONS로 S42를 가리킨다. 확인 시 선택한 공지 메타데이터/revision만 변경하며 옛 진행 단계를 복원하지 않는다. 다른 공지와 관계·성장·경기·돈은 유지한다.

기존 v4 이적 영수증의 sharedRelationKeys 부재를 허용한다. 이전 저장 읽기에서 재회 근거나 사건을 소급 생성하지 않는다. 성공한 새 이적만 선택 필드를 기록하며 기존 원장/스키마 버전/의존성을 변경하지 않는다. 이전 바이너리는 E96 읽기를 지원하지 않으므로 새 저장의 구버전 실행을 보장하지 않는다. 롤백은 코드와 이전 저장 snapshot을 함께 보존하며 새 근거를 임의 삭제하지 않는다.

이번 범위는 주인공의 실제 시즌 중 이적이다. AI 오프시즌 영입으로 내 구단에 온 관계, 군팀 복귀, 다른 진로의 공동 등록은 아직 미연결이다. 실제 UI/계정/Neon 저장·미국 실제 리그도 후속이다. ui-ux-pro-max의 기존 승인 시각 방향은 유지하고 UI가 생길 때 가시적 포커스/가려짐/뒤로 가기를 검사한다. 렌더 검수 완료로 세지 않는다.
