# M2-AE — 미국 직행 오퍼·기한·마이너 계약 예약

2026-10-21. 평균 성장/6능력/잠재력 생성은 바꾸지 않는다. M2-AD의 미국 평가65를 실제 고교/대학 졸업 명령과 연결한다. 사용자 추가 확정은 제안 후30게임일 유효다.

## 연결된 동작

- us-direct.ts: 신뢰된 US 모집 재고(snapshot)의 실제 빈 자리·가용 USD 예산을 확인한다. 최종 평가65 미만/자격 없음/자리·예산 부족이면 제안0이고 미국 카드를 숨긴다. 구단은 자동으로 만들지 않는다. score70 이상은 A, 그 미만은 Rookie이며 MLB 즉시 출장을 보장하지 않는다.
- 같은 평가의 독립 seed 스트림으로 평가1회와 중복 없는 최대3개 적격 구단을 고정한다. 적격 목록을 ID순 정렬 후 난수로 최대3개를 택하는 것은 구현 기본값 D다. 고정 제안은 조회/JSON 복원으로 재추첨하지 않는다. 계약금은13의 기존50~90 점수 선형곡선($50,000~$2,000,000)을 유지하고 연봉$30,000/보유6시즌을 표시한다. 차출/복무 복귀 옵션은 모집 재고가 제공한 조항을 그대로 표시한다.
- career-us.ts: 졸업 진로·현재 선수·공식 고교/대학 보정성적·스카우팅 전망을 묶어 발급한다. 숨김 실제 P를 평가점수에 직접 쓰지 않고 스카우팅 평가 범위의 중앙값을 사용한다. 준비/수락 시 revision·학교 진로 근거·프로그램/이벤트 버전을 확인한다. 임의 점수/평가범위 재작성은 거절한다.
- 제안 후30게임일은 issuedWorldDay≤현재일<issuedWorldDay+30. advanceCareerUsNegotiation은 경과일을 저장하고 기한에 멈춘다. 학교 공식 경기/건강/성장 원장을 가짜 경기로 늘리지 않는다. 만료 후 미국 카드는 숨기고 수락은 거절하며 국내/대학은 유지한다. 전체 거절 후 재발급도 금지한다.
- 수락은 US_MINOR 예약 계약/미국 권리/초기 레벨/계약금 수입 예약의 단일 receipt를 남기고 us-reservations.ts가 실제 모집 재고의 해당 레벨 빈 자리1개와 계약금+첫해 연봉을1회 예약 차감한다. 동일 receipt 재시도는 no-op이며 다른 내용 재사용/낡은 경쟁 재고는 거절한다. 초기 재고에서 receipt들을 순서대로 재생해 현재 자리/예산/등록 예약 수를 검증한다. reserved status와 PENDING_SEASON_ACTIVATION으로 다음 시즌 활성화와 구분한다. 서명일도 보존한다. 계약금은 아직 실제 수입 원장에 게시하지 않는다. 활성화 작업자는 동일 entryKey/receiptKey로1회만 게시해야 한다.
- 같은 revision에서 국내/미국 선택은 하나만 성공한다. 미국 서명은 기한 내 미수락 KBO 제안을 거절하고 이전 모집을 보존한다. KBO 서명·대학 입학은 미국 모집을 closedBy와 함께 이전 이력에 보존한다. 대학 졸업은 E75를 다시 열거나 학적/나이를 재처리하지 않는다.
- 공개 오퍼 DTO는 고정 조건/기한/상태/미노출 사유만 허용한다. raw P/seed/RNG/sourceBasis는 노출하지 않는다. 숨겨진0개 오퍼 카드나 적용100% 배지를 만들지 않는다.

## 입력 경계와 아직 남은 것

UsRecruitmentWorld는 전체 미국 리그가 아니라 세계 작업자가 제공할 모집 재고다. 현재 자동 미국30조직/120~160명 선수단 생성·다수 NPC의 공유 세계 연결·마이너 시즌 등록/경기·레벨 이동은 미구현이다. 실제 API/UI에서 임의 클라이언트가 재고·예산·자격을 제출하게 만들지 않는다. 테스트의 가상 조직/자리/예산은 통제 fixture이며 실제 리그가 생성됐다는 증거가 아니다.

고교/대학 경로에서 명시적 prepareCareerUsDirect 호출 후에만 제안이 나타난다. 실제 세계 재고 공급자가 연결되기 전 기존 saves에는 미국 카드가 자동으로 생기지 않는다. 계약 수락이 실제 계정/DB 저장·활성 리그 등록/수입 지급·MLB 데뷔 완료를 뜻하지 않는다.

협상 clock은 모집의 currentWorldDay에 저장했다. 이후 공유 세계 연말/리그 날짜 작업자는 서명/종료 경과일을 읽어 같은 기간을 다시 진행하거나 성장/건강을 중복 정산하지 않아야 한다. 현재 학교 기록의 days는 공식 경기 원장으로 보존한다. 다른 졸업시즌의 미국 모집은 별개 평가지만 같은 졸업시즌은 새로 뽑지 않는다.

## 호환·검증

새 usRecruitment/previousUsRecruitments/US 다음시즌 예약 phase는 선택 필드로 추가했다. 기존 save의 필드를 다시 뽑거나 작성하지 않으며 모집이 없으면 기존 공개 DTO 모양을 유지한다. 신설 프로그램 schemaVersion1은 source snapshot/점수/구단/RNG/receipt를 재계산 검증한다. 되돌릴 때는 새 모집 writer만 중단하고 이미 생성된 예약/history reader는 보존한다.

관련23/23(71.69초)을 통과했다. 고교 타자/투수 및 통제된95능력 대학4년 fixture의 실제 선수권/졸업·미국 수락,30일 만료,국내/미국 경쟁 선택과 예약 재시도/변조를 확인했다. 대학95 fixture는 자연 성장이나4년 정규864경기 완주를 뜻하지 않는다.

첫 대학 fixture 검사에서는 선수/성장 원장의 시작값 불일치로 CHANGED_GROWTH_SEASON이 발생했고, 원장까지 일관되게 수정했다. 이후 readonly 능력치 직접 쓰기 타입 오류를 새 능력치 객체 할당으로 고쳤다. 제품 성장·타입 검사를 약화하지 않았다. 실패 로그는 성공 증거가 아니다.
