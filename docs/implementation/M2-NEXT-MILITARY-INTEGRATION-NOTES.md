## 연결할 때 보존할 것

- 10팀 일정과500명/3난이도 생성 해시·옛 저장값을 버전 호환한다. 군팀은 원구단의 추가 중복 출장 팀이 아니다. military 소속은 한 리그 등록만 사용한다.
- 현재 KboInitialContract는 ACTIVE/연 단위다.21의 계약 정지·remainingPaidGameDays·실제 지급/예약/반올림 잔여/보유권/복귀는 별도 호환 마이그레이션이 필요하다. 서비스마다 계약연수+1로 대신하지 않는다.
- SPORTS/ACTIVE 두 블록과 실제 완료 worldDay, ATHLETE_SERVICE3시즌/메달은 서로 다른 근거다. 메달을 즉시 COMPLETED로 만들지 않는다.
- 원구단·군팀 성장/구종XP/강화 공통 연간 원장과 실제 등록을 공유한다. 등록 연차 BV는 KBO 정규만 센다. 상무 퓨처스/현역은 연차0이다.
- 현재는 실제 후보를 선발하며 상무가 야수9명·선발1명을 채우지 못하면 일정 확정을 거절한다. 부상/긴급 등록과 정상 첫 기수·반년 복귀는 후속이다. 이름뿐인 빈 팀이나 임의 스타로 편성을 강제하지 않는다.
- CE의28세 차단은 명시 병역 기록이 있는 커리어만 대상으로 한다. 신규/옛 저장의 병역 대상 고정과 초기 NPC 배경 이력은 후속이다. 기존 미연결 세이브를 읽으며 모두 복무완료 처리하지 않는다.
