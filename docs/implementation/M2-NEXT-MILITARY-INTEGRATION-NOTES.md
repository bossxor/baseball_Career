## 2026-10-23 군팀 비상 보충 — 사용자 확정 U

사용자는 상무에서 부상으로 건강한 야수9명·투수1명을 채우지 못하면 군팀 전용 낮은 능력의 가상 선수를 필요한 만큼만 임시 등록하고 원래 선수가 복귀하면 제외하는 안을 승인했다. 매년 야수10·투수10 정규 선발과는 별도 비상 보충이다. 조기 입대나 기권으로 대신하지 않는다. E95/E96 공동 검사 완료 뒤 설계14/21에 사용자 결정을 반영했다. 실제 군팀 보충 구현·실행 검증은 후속이며 완료로 세지 않는다.

연결 조사(코드 변경 없음): kbo-day.ts는 군팀 피로는 정산하지만 SANGMU 건강 원장을 의도적으로 건너뛴다. kbo-game-world.ts는 members/loaned만 경기 명단으로 투영하고, 일 마감 등록 검증도 world.players 또는 members만 허용한다. 임시선수에 가짜 복무 프로그램·계약을 만들어 members에 끼워 넣으면 보유권/복무 완료를 위조하므로 사용하지 않는다. 임시 명단과 이전 출장의 이름/기록 근거를 보존하는 경계를 정한 뒤 두 경로와 명단 부족 복구 지점을 함께 연결한다. 기존 군팀 건강 미연결 저장은 건강 RNG를 소급 소비하거나 옛 경기 원장을 재작성하지 않도록 적용 시점을 분리해야 한다. 실제 변경 전에는 Sangmu 멤버를 조회하는 통계·성장·구종XP·복귀 호출자도 모두 검색한다.

최소 보충 계산은 기존 emergency-roster.ts의 planEmergencyRoster를 재사용한다. 이 함수는 건강한 야수9/투수1뿐 아니라 C·2B·3B·SS의 우투 수비수4명도 보장하므로 새 인원 계산기를 중복 구현하지 않는다. 해제는 명단 제외이며 이미 출장한 임시선수의 이름·기록 근거는 남겨야 한다. 기존 high-school-emergency.ts의 등록/해제·신원 보존 패턴을 참고하되, HS/COLLEGE 전용 ID/나이/능력 분포와 저장 RNG를 군팀에 그대로 덮어쓰지 않는다. 구체 생성 수치·활성화 버전은 아직 구현 확정하지 않았다.

조회 경계 추가 조사: kbo-relations.ts의 detachedPlayers는 FA/은퇴 원장과 과거 등록을 읽지만 현재 Sangmu members를 직접 조회하지 않는다. 복무 중인 NPC가 world.players에서 빠진 상태의 S42 이름·소속 조회를 실제 입대 fixture로 재현하고, 경기용 명단/계약을 바꾸지 않는 읽기 adapter에서 해결할 필요가 있는지 다음 단계에 검사한다. 아직 결함 재현·수정/검증 완료로 세지 않는다.
