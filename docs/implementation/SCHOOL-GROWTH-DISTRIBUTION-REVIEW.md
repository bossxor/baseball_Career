# 고교 성장·NPC 분포 검토 — 2026-10-21

최신 상태: NPC 희소 스타/개별 편차 축소를 선택했고, 이후 플레이어 성장2배는 철회했다. 미국 종합52 조건도 폐기하고 스카우트 평가65를 선택했다. 아래는 당시 비교 기록이며 현행 규칙은 [버전2 구현/검증](M2-AD-SCHOOL-BALANCE-V2.md)과 설계14/13/34를 따른다.

사용자는 미국 직행 종합52를 유지하고 고교 성장량을 조정하는 방향을 선호했다. 동시에 고교 선수의 대부분이 평균 주변에 모이고, 극단적으로 낮거나 높은 선수는 드물어야 하며, 학교마다 상한65 선수가3~5명씩 배치되는 구성을 원하지 않는다고 명확히 했다. 주인공이 육성으로 두각을 나타낼 여지가 있어야 한다.

## 현재 코드 실측

scripts/analyze-school-npc-balance.mjs로 서로 다른 seed200개 세계에서 NPC44,800명을 생성했다. 주인공은 집계에서 제외했다. 현재 종합은35~65, 최빈48 삼각분포이며 평균은49.3041이었다. 종합65는44,800명 중23명, 한 학교에 최대1명. 하지만 종합60 이상은 한 학교에 최대6명이었다. 현재 분포의 이론상60 이상 비율은약5.93%, 리그 NPC224명당평균13.29명이다. 상한65가 여러 명씩 보장되는 코드는 없지만 상위권의 폭은 사용자가 원하는 것보다 넓을 수 있다.

65는 NPC 종합점수의 초기 생성 상한이다. 개별 파워/제구 등의 상한65가 아니다. NPC는 유형별6능력 배열에 같은 종합 offset을 더하므로 종합48이라도 개별 파워68 등은 가능하다. 종합 분포만 좁히는 것과 개별 유형 편차를 줄이는 것은 다른 변경이다.

## 제안 비교 — 아직 미적용

초기 NPC 종합을 평균48의 범위35~65 절단 정규분포로 생성하는 안이다. 경계 밖 값을35/65로 밀어 붙여 상한/하한에 몰리게 하지 않는다. 아래는 이론적 모형 비교이며 현재 게임의 새 규칙이 아니다.

| 분포 | 종합44~52 | 종합60 이상 | NPC224명 중60 이상 기대 인원 |
| --- | ---: | ---: | ---: |
| 현재 삼각분포 | 50.84% | 5.93% | 13.29명 |
| 제안 평균48·표준편차4 | 73.98% | 0.201% | 0.45명 |
| 제안 평균48·표준편차5 | 63.51% | 1.044% | 2.34명 |

인원을 학교별로 강제로 채우는 quota가 아니다. 드물게 스타가 겹치는 해는 가능하며 같은 seed는 같은 결과를 재현해야 한다. 대학/프로 분포는 이 검토로 자동 변경하지 않는다. 주인공 초기 유형 능력은 유지하고 고교 NPC의 유형 편차도 별도로 줄일지 사용자에게 질문했다.

## 주인공 고교 성장 검토 — 계수 미확정

NPC 초기 생성 분포와 주인공의 고교 기간 성장량은 분리한다. 기간 성장2배를 주인공의 고교 기간에만 적용하는 산술 후보를 계산했으며 NPC·대학·프로의 성장 배율을 함께 올리는 안이 아니다. 같은 난이도의 기본 난이도 배율은 별도로 유지한다.

대표연도2029~2032에서 충분한 출장/부상 없음·시작 종합50·확정 강화+1을 가정한 단순 예산 상한 계산은 일반 약53.15~53.36, 하드 약52.15~52.30이었다. 잠재력/실제 출장/부상/분배를 적용한 실제 전체 경기 통합 검증은 아니다. 종합70으로 일괄 상승시키거나 NPC의 시작 분포를 올리는 계산은 아니다.2배 계수는 아직 승인·적용하지 않았다.

기존 성장 원장은 당시 규칙으로 재계산 검증하므로 실제 변경 때는 기존 저장값의 규칙 버전/지급 이력을 보존해야 한다. 이미 지급한 성장을 새 계수로 다시 지급하거나 기존 세이브를 손상시키지 않는다.

## 사용자 선택 대기

2. 종합 분포만 좁힐지, 주인공 초기 유형은 유지하면서 고교 NPC의 개별 유형 편차도 줄일지.

## 검증과 실제 변경 시 주의

현재 분석 재현·전체 린트·설계 정적10종을 통과했다. 게임 패키지 소스는 변경하지 않아 게임 테스트 전체/빌드를 다시 실행하지 않았다. 생성식을 바꿀 때도 신규 생성 버전과 기존 생성 버전을 구분하고, 저장된 NPC를 재추첨하지 않는다. 기존 고교 세계 골든6종/게임 M1 골든과 과거 seed 재생 계약을 임의로 새 기대값으로 덮지 않는다. 새 분포와 NPC 유형 편차의 구현 검증은 사용자 선택 후 진행한다.
