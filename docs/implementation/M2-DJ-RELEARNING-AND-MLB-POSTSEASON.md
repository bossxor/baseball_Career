기존 체크아웃에서 직접 구현한다. 직전 DI230897f는 main/작업 브랜치 모두 푸시했고 전체671+웹20 통과(Neon2건 환경 부재 건너뜀)했다.

## 구현

사용자 확정: 분기4회/예약 해제가 끝난 숙련0 구종은 연말 진입을 막지 않는다. 기존 XP 그대로 다음 시즌에 보존하고 PRE에서 다시 선택할 수 있다. 새해 학습1회와 base10 예약을 사용하며 XP 초기화/무료 지급/과거 미지급분 소급 없음. 공통 연말 검사와 학습 함수를 수정하고 실제 고교→대학 전환/같은 구종 재선택 회귀 검사를 추가했다.

MLB PS는 AL/NL 각15팀의 실제 정규기록으로6팀씩 선정한다. 인터리그 성적을 포함하는 순위 부분집합 조회를 공통 standings에 추가했고 기존 호출은 그대로 동작한다. WC3-6/4-5, DS5전, CS/WS7전, 상위2팀 부전승·고정 대진·게임 홈 배치를 구현했다. 매복원시 승자 목록에서 브래킷을 재생해 승수/참가 팀 변조를 거부한다. AL/NL 소속은 서버 고정 레지스트리 입력이며 화면에서 고르는 입력이 아니다.

실제 PS worker는 기존 경기/부상/피로/XP/특성/부상 대체 함수를 재사용한다. 하루1경기·1000PA/20완료이닝 상한·중간 저장·정규 급여/성장 중복 없음. PS 통계 영수증과 결과를 봉인해 최종 연간 성장에서도 변경을 거부한다. 공개 view는 구단/대진/승수/우승만 내보낸다.

## 집중 증거

구종·대학 이월 등23/23. 순위/브래킷/연간 성장/실제 PS8/8. 정규시즌 입력은 통제된8790기여 fixture이며 실제8790경기 완주가 아니다. PS는 실제 경기 엔진으로 전체 우승까지 진행했고 타석1개만 진행한 실제 pending 저장을 JSON 복원한 결과도 직접 진행과 동일했다. 최대53경기와 홈 배치는 순수 브래킷 경계 검사다. 최종 공개 view도 전체 묶음에서 숨은 잠재력/RNG 미노출을 확인했다. 실제 PS46경기(day240~285), 우승US25, 급여30000 유지.

초기 시험에서 옮긴 fixture의 미사용 import와 PS 완료 wrapper 타입을 고쳤고, pending fixture가 정상 사전 로스터 준비를 거치도록 수정했다. 이 수정 전 실행을 최종 통과로 합산하지 않는다.
