# M2-CO — 병역 계획·28세 기한·현역 복귀 컨디션

## 연결한 동작

군 기록 필드가 없는 기존 커리어도 미해결로 읽는다. 27세 시즌을 마치고 다음 28세 시즌을 시작하기 전에는 입대를 확정해야 한다. 기존 저장이 이미 28세를 넘겼어도 같은 안전장치를 적용한다. 25·26세의 남은 유예 시즌과 27세 마지막 유예를 공개 조회한다. 45세 은퇴는 병역 완료를 거짓으로 만들지 않고 기존 은퇴 경로로 처리한다.

오프시즌의 명시 명령 openKboMilitaryPlan으로 E49(27세 미만) 또는 E54(27세 이상)를 한 시즌 한 번 연다. E30 제안을 여는 기존 방식과 같다. 실제 홈에서 이를 여는 UI 연결은 M4 작업이며 자동 사건 팝업까지 구현했다고 하지 않는다. 연도 전환의 28세 차단은 사건을 열었는지와 무관하다.

START_SERVICE는 S26 확인 화면으로 이동하는 결과만 반환한다. 이 선택만으로 입대를 확정하거나 기한 차단을 없애지 않는다. 실제 입대는 confirmKboActiveService가 담당한다. APPLY_MILITARY_TEAM은 기존 상무 지원/E50 결과를 연결하며 28세 이상·부상 중에는 비활성이다. 유예는 26세 이하에서만 허용한다. 사건 키·버전·리비전이 맞지 않으면 원본을 바꾸지 않는다.

새 현역 복귀는 실제 복무 완료일 다음의 등록 팀경기부터 6경기 동안 유효 능력에 0.95를 적용한다. 벤치·부상 등록도 팀경기 수에 포함하고 휴식일·국가대표 경기는 제외한다. KBO/FUTURES 정규·포스트시즌의 공식 경기와 건강 등록 영수증을 함께 대조한다. 시즌을 넘어도 누적하며 같은 날 재처리로 횟수를 다시 쓰지 않는다. 영구 능력치·잠재력·커리어 최고값은 바꾸지 않는다.

현재 경기 스냅샷의 기존 effective multiplier 채널(morale 필드)에 0.95를 고정하므로 중간 저장/JSON 이어하기도 같다. 일반 경기의 기본값 1과 기존 경기 프로토콜·골든 값은 유지한다. 나중에 별도 사기를 연결할 때는 이 값을 덮어쓰지 말고 곱해야 한다.

## 저장 호환

KBO 루트 v3는 계획 사건 열기·새 연도 개시·새 현역 확정/복귀에서 명시적으로 생성한다. 새 guard는 v1/v2/v3를 읽고 학교 v1 guard는 그대로다. 이전 CN의 KBO v1/v2 전용 guard는 v3 진행을 거절한다. 이것은 엔진 루트 버전이며 배포된 모든 구버전 앱을 통합 시험했다는 뜻은 아니다. 롤백은 해당 전환 전 저장과 코드의 동시 복원이며 버전 숫자만 내리지 않는다.

이미 완료된 옛 복무에 returnCondition이 없으면 소급 6경기를 만들지 않고 보정 1을 유지한다. 새로운 실제 현역 완료에서만 원장을 만든다. 저장된 등록 키가 바뀌거나 공식 경기 근거가 사라지면 조용히 초기화하지 않고 오류를 반환한다.
