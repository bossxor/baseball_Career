# M2 결과·은퇴 표시 구현 — 2026-11-10

- 결산: KBO 포스트시즌 시드와 기존 leagueStandings로 확정 정규 순위, 현재 등록 및 포지션, 역할 변경 영수증, 에이전트 수입 영수증 종류별 총액·수수료·실수령을 기존 sections/lines에 표시한다. 영수증이 없는 금액은 추정하지 않는다.
- 은퇴: 기존 공개 업적 조회의 완료 항목, 당사자에게 귀속된 연간 수상·올스타 영수증, E24 이정표를 표시한다. 점수·내부 영수증·숨은 능력은 공개하지 않는다.
- 빛난 3년은 지표·동률·리그 간 비교 기준이 미정이므로 산출하지 않았다. 미국·학교·대학 확정 순위와 영수증 없는 보수 세부도 추정하지 않았다.
- 테스트는 작성만 했으며 테스트·빌드·타입·린트는 지시대로 미실행이다. 실제 화면·대용량·기존 저장 호환은 통합 검증이 필요하다.

## CH 표시
정규시즌 동일 리그의 이전 시즌 개인 공식 기록이 있을 때만 안타·홈런·볼넷·투수 탈삼진·승·세이브의 이전 최고를 초과한 값을 CH로 표시한다. 이전 표본 없음, 동률, 율 지표는 표시하지 않는다. 첫 시즌 및 다른 리그·동률 구분 테스트는 작성했으나 실행하지 않았다. 빛난 3년 선정 기준은 여전히 미정이다.
