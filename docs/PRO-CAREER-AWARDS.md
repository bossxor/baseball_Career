# Pro career awards

`pro-career-awards.ts` applies design 08, 01 and the newer event rules in design 45. These are game formulas, not official KBO award formulas. KBO, FUTURES and each US level retain separate receipts.

- Call `observeProCareerAwardGame(career, finalGame)` immediately after the matching official record commit. It preserves actual input fielding positions, defensive ability and pitcher role for every participant. It does not alter game inputs, IDs, seed, probability or record schemas. Unknown legacy fielding positions remain unknown; current player position never fills that history.
- Call `refreshProCareerAwards(career, fullyClosedDay, firstProSeasonByPlayer)` after each complete day. It publishes E25 from records through the scheduled league midpoint, requiring all fixtures through that day. Candidates meet half the full scheduled regulation denominator. Each position selects `ceil(qualifiedCandidates * .25)` by contribution, exposure and immutable ID. No All-Star game exists in v1. E25 remains once per player season, including level changes.
- Annual receipts require every actual regular fixture committed. They use batting/pitching contribution, separate population z scores (zero standard deviation gives zero), MVP minimum PA 200 / outs 150, most-played defensive position and 50 games there, SP 15 starts, RP 30 relief outings, and CP positive saves with saves/ERA/outs/ID ordering. AVG and ERA titles require team-game regulation denominators. Exact rate ties share titles. MVP, rookie and position ties use exposure then ID.
- Rookie candidates require authoritative first professional registration seasons. The optional server-owned map must come from entry/draft/contract receipts. An NPC's current registration is not proof of rookie status. Unknown rookie status cannot win this award.
- E29 is emitted only from an annual receipt naming the protagonist, once per award type across the career. Read views and acknowledgement expose the existing event contracts.

Legacy hitters missing any game assignment are excluded from contribution awards; their defensive contribution cannot be reconstructed honestly. Pitcher contribution still uses recorded outs/ER/K. Team-dependent rate qualification needs actual appearance proof. Title names for cumulative metrics are unspecified in canonical documents, so `positiveCumulativeAwardLeaders` implements positive-record/shared-tie rules without inventing award categories. No cumulative award receipt is generated until those categories are specified.

Tests cover immutable FINAL evidence, unknown legacy assignments, invalid positions, replay, most-played positions, qualification boundaries, rookie proof, z-score ties, separate leagues, midpoint selection, completed-schedule gating and repeated publication. Runtime verification is deferred to the parent task's single final check.
