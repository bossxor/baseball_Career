# SLB Career UX 분석

**직접 관찰 0건.** 접속 결과는 [플레이 기록](SLB_CAREER_PLAYTHROUGH.md)에 있다. 아래 기준은 우리 프로젝트에서 확인할 항목이다.

| 관찰 항목 | SLB Career | 다시, 플레이볼 확인 기준 |
| --- | --- | --- |
| 선수 생성과 진입 | 확인 필요 | 종류, 포지션, 능력 선택 후 첫 경기까지 다음 행동이 분명한지 |
| 시즌 진행 | 확인 필요 | 시즌·월·일 진행 중 사건·요청 제한으로 멈춘 이유와 재개 버튼이 함께 보이는지 |
| 성장·기록 | 확인 필요 | 최근 변화와 시즌 누적을 빠르게 구별하는지 |
| 드래프트·계약 | 확인 필요 | 조건과 결과를 한 화면에서 비교하고 확정할 수 있는지 |
| 시각·모바일 | 확인 필요 | 전환, 이미지 크롭, 키보드와 터치 동선이 작은 화면에서도 자연스러운지 |

비교 후 적용할 항목은 사용 목적과 증거로 선택한다. 자체 네이비 청춘 야구 일러스트, 국내 진로·병역·해외 복귀 흐름, 공식 기록과 저장 재개 규칙을 사용한다. 원작 고유 요소는 제품 자산으로 채택하지 않는다.
