## 차별화로 유지할 것

- 국내 진로·병역·해외 복귀·재도전 예산(66)처럼 원작에 없는 실패 후 경로. 원작은 고졸 미지명 뒤 대학만 보였다.
- 계약 거절과 다중 오퍼 비교. 원작은 지명 즉시 입단만 가능했다.
- 공식 기록 정확성: 원작은 타자에게 투수 지표를 보였다. 우리는 종류별 기록 분리를 테스트로 지킨다.
- 시각: 자체 승인 청춘 야구 애니 컷, 원작 구단명·엠블럼·문구 미사용.
