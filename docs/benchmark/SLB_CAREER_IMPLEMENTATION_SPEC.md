# SLB Career 벤치마킹 구현 설계서

다른 팀이 이 문서만 보고 '다시, 플레이볼' 화면·흐름을 구현할 수 있게 정리한 기준서다. 관찰 원문은 [플레이 기록](SLB_CAREER_PLAYTHROUGH.md), 우선순위는 [백로그](SLB_CAREER_BACKLOG.md), 비교 요약은 [UX 분석](SLB_CAREER_UX_ANALYSIS.md)이다.

## 0. 사용 규칙

- **복제 금지.** 원작의 코드·이미지·로고·구단명·문구·화면 디자인을 쓰지 않는다. 아래 "관찰"은 동작 패턴만 기록했다. 문구는 우리 [사건 문구](../design/09-EVENT-COPY.md)·[UX 설계](../design/03-UX-DESIGN.md) 톤으로 새로 쓴다. 시각은 승인 청춘 야구 애니 컷([자산 목록](../assets/ASSET_INVENTORY.md))과 기존 CSS 토큰을 쓴다.
- **우리 규칙이 우선한다.** 수치·확률·계약·병역·기록 규칙은 [확정 결정](../design/14-CANONICAL-DECISIONS.md)과 각 설계 문서가 기준이다. 원작 수치(예: 능력 20점 척도, 상무 상위 30%)는 참고일 뿐 채택하지 않는다.
- **서버가 준 값만 표시한다.** 웹은 엔진을 import하지 않는다(`apps/web/src/model.ts` DTO). 잠재력·seed·RNG·드래프트 점수 원값은 노출하지 않는다([확률 표시](../design/38-PROBABILITY-DISPLAY.md), [잠재력](../design/67-POTENTIAL-ASSESSMENT-PROGRESSION.md)).
- 상태 표기: **채택**(같은 패턴), **변형**(우리 규칙으로 바꿔 적용), **불채택**(이유 명시).

## 2. 핵심 루프 (관찰)

`생성 → 고3 시즌(1클릭) → 진로 카드 → (드래프트|대학) → 지명·서명 → [스토브리그 허브 → 시즌(1클릭, 정지 이벤트 가능) → 시즌 결과 → (FA/연장/병역/대표 결정)] × N → 은퇴 → 기록 보관 → 다음 생`

결정 지점에서만 멈추고, 그 외에는 버튼 한 번에 한 시즌이 지나간다. 우리 쪽 대응: 연 단위 빠른 진행 CTA(Codex 팀 a4c4209), 정지 사유 표시(106ae9d), [상태 기계](../design/19-CAREER-STATE-MACHINE.md).

## 3. 기능별 명세

표기: **엔진** = `packages/engine/src` 존재 여부(파일명), **웹** = 현재 화면 연결 여부. "확인 필요"는 이 문서 작성 시 코드에서 확정하지 못한 항목이다.

### SLB-01 선수 생성 [변형]
- 관찰: 이름·등번호·투타(우우/우좌/좌좌)·투수/타자·희망 구단·출신 고교 한 화면. "랜덤 생성"은 이름·구단·학교만 채우고 투타·유형은 유지. 포지션은 생성 시 자동 배정 후 성장방향 단계에서 변경.
- 우리: [생성 필드](../design/79-CREATION-FIELDS-VALIDATION-COPY.md) 8단계 탭 유지. 적용할 것: 랜덤 채우기 버튼(이름만, 선택 필드 유지), 유형별 "추천" 배지(서버 계산).
- 엔진/웹: 생성 있음(`Create.tsx`). 랜덤 버튼·추천 배지 없음.
- 수용: 랜덤은 이미 고른 필드를 바꾸지 않음. 추천은 서버 응답 값만.

### SLB-02 능력 후보 3장 공개 [변형]
- 관찰: 뒷면 카드 3장(유형 라벨) "모두 공개" → 카드 선택 시 아래 리포트 막대가 바뀜. 합계 고정. 유형 이름은 매번 다름.
- 우리: [아키타입](../design/34-ARCHETYPES-COLLEGE-ODDS.md)·[6능력](../design/35-SIX-ABILITIES-FOUR-FOCUS.md). 후보 비교형 공개는 생성 미리보기 패널을 카드 3장 비교로 바꾸는 형태로 적용.
- 수용: 후보 값은 서버가 생성(재시도로 다시 뽑기 불가 여부는 설계 42 규칙 따름). 키보드로 카드 선택 가능.

### SLB-03 시즌 1클릭 진행과 진행 연출 [채택]
- 관찰: 고교는 전국대회 3개가 차례로 채워지는 연출, 대학은 나이 타임라인(19→20→21), 프로는 월 칩(APR~OCT) 진행 바. 수 초 후 결과 화면.
- 우리: 연 진행 CTA 있음. 진행 중 화면은 서버 진행 상태(월·대회)만 표시.
- 수용: 연출은 진행 응답과 독립된 표시용, `prefers-reduced-motion` 시 즉시 결과.

### SLB-04 시즌 중 정지 이벤트 [채택]
- 관찰: 시즌이 "SEASON PAUSED" 카드로 멈춤. 예: 1군 콜업(이전 소속→새 소속), 국가대표 선발(참가/불참). 확인 후 같은 시즌 계속.
- 우리: E08/E09 콜업, 국제대회([20](../design/20-INTERNATIONAL-COMPETITIONS.md)), 정지 사유 표시 구현됨.
- 수용: 정지 카드 1장 = 서버 사건 1개, 선택 후 정확한 날짜에서 재개(기존 원칙).

### SLB-05 시즌 결과 화면 [변형]
- 관찰 순서: 역할 변화 배지(신인→1군 주전) · 한 줄 시즌 평가 · 기록 카드(홈런·안타·타점 / 타율·출루·장타·OPS, 투수는 승·이닝·탈삼진·ERA·WHIP·K/9) · CH(커리어 하이) 표시 · 타이틀 트로피 · 타구 지표(최고·평균 타구속도, 강한타구·발사각·뜬공·배럴 %, 전년 대비 화살표) · OVR 변화와 능력별 증감 · 팀 순위(정규/최종)·승패 · 국가대표 선발 행 · 코멘트 1~2개 · 연봉 내역(계약 연봉+1군 보전금=총보수). 숫자는 0에서 카운트업, 마일스톤 토스트("100홈런까지 N개")는 탭해야 닫힘.
- 우리: 공식 기록 정확성 우선. 적용: 역할 변화 배지, CH 표시, 능력 증감 칩, 팀 순위 줄, 코멘트(사건 문구 규칙), 연봉 내역. **변형**: 타구속도·배럴 같은 물리 지표는 우리 엔진에 없는 값이므로 표시하지 않음([24](../design/24-GAME-ENGINE-SCORING.md)에 해당 산출이 생길 때만). 토스트는 자동으로 사라지고 탭을 강요하지 않음.
- 엔진: 기록(`records.ts`), 수상(`pro-career-awards.ts`), 성장 원장 있음. CH 판정·마일스톤 잔여 계산은 확인 필요.
- 수용: 모든 수치는 공식 기록 원장 값, 미완료 경기 수치 미공개. 카운트업 중에도 스크린리더는 최종값을 읽음.

- 투수(4차): 보직별 상단 지표가 다름(불펜=홀드·경기·탈삼진·ERA·WHIP·K/9, 선발=승·이닝·탈삼진…), 구종 이름+문자 등급과 등급 상승 표시(↑), 1군 합류 시 역할 문구(예: 추격조)와 설명 한 줄. 우리: 보직별 지표 구성과 구종 등급 변화는 [48](../design/48-PITCHES-BATTING-APPROACH.md)·[57](../design/57-REPERTOIRE-DETAILED-CONTRACT.md) 원장 값으로 채택. 모달 뒤에 0·"?"가 보이는 구성은 따르지 않음.

### SLB-06 스카우팅 리포트 [변형]
- 관찰: 능력별 문자 등급(S/A/B/C/D)·체격·서술 2~3문단. 투수는 최고/예상 최고 구속 범위, 구종 3개 등급.
- 우리: 잠재력은 범위만([67](../design/67-POTENTIAL-ASSESSMENT-PROGRESSION.md)). 현재 능력 등급 + 잠재력 범위 문구로 변형. "예상 최고 구속" 같은 미래 값은 범위·문구로만.
- 수용: 등급 경계는 서버 상수, 잠재력 원값 비노출.

### SLB-07 진로 결정 카드 [채택 → 일부 구현됨]
- 관찰: 경로별 카드에 지명 확률 %, 예상 라운드, 실패 시 대안 문구("미지명 시 대학 진학 가능"), 대학 카드는 기간·다음 결정 학년·남은 기회. 같은 카드를 두 번 누르면 확정("선택됨·한 번 더 누르면 진행"). 대회 성적이 확률에 반영된 것으로 보임(같은 OVR대에서 35%→95%) [추정].
- 우리: 2026-11-07 `FlowCommand.facts` 추가(21a9703)로 자격·결과 줄 표시 시작. 확률 표시는 [38](../design/38-PROBABILITY-DISPLAY.md) 규칙.
- 남은 일: 고교 진로·대학 2학년(E73)·재도전 경로 화면이 같은 카드 형식 사용, 2탭 확정은 되돌리기 쉬운 선택만.

### SLB-08 드래프트 공개와 지명 카드 [채택]

- 우리: **변형** — 계약 거절·다중 비교 유지([40](../design/40-SCOUTING-RECRUITMENT-ODDS.md), E05/E07). 공개 연출만 채택.

### SLB-09 계약 서명 [채택 → 구현됨]
- 관찰: 서명 패드(손글씨) 또는 이름 서명, 서명 전 입단 비활성. FA 계약서는 저장된 서명 자동 재사용.
- 우리: `FlowCommand.sign` 서명 단계 구현(eb327cd, 표시 전용). 남은 일: FA·재계약 계약서에도 같은 단계, 브라우저 검수.

### SLB-10 스토브리그 허브 [변형]

- 우리: 커리어 화면(`Career.tsx`)+흐름 화면(`Flow.tsx`). 상단 고정 선수 헤더 구현(21a9703). 적용: 연봉 3칸 요약, 보장 계약 진행 표시.
- 수용: 버튼은 서버 `nextActions`/`commands`만.

## 4. 원작 결함 — 따라 하지 않을 것

- 타자에게 투수 지표 표시, 대학 시즌을 "프로 0년차"로 표기.
- 재협상·트레이드·병역의 확인 없는 즉시 실행.
- 레이아웃 이동 중 다른 카드가 눌림(진입 팝업 닫힘 직후).
- 1군 기록 없는 은퇴의 빈 요약, 복무 연도 로그 누락(2차 관찰).
- 마일스톤 토스트가 탭 전까지 진행을 막음.
- 모달 뒤 결과 지표가 0·"?"로 보여 혼동(4차). 시작한 훈련을 끝내야만 진행 가능.
- 여러 모달(이정표·보직 변경·국가대표)이 겹쳐 결과가 20~30초 0·"?"로 보이고, 모두 닫기 전 '다음'이 무반응(5차).
- 오프라인 저장 선수가 팀 슬롯 후보에 나오지 않음(5차).
- 부상·선발 전환이 사실상 없어 위험 요소가 약함 — 우리는 건강 원장([K 건강](../implementation/M2-K-HEALTH-EMERGENCY.md))을 유지.
