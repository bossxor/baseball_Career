| 직접 관찰 | 브라우저 승인 결과만 확인. 게임 화면, 조작, 결과, 캡처 없음 |

접근이 허용된 후 시작, 선수 생성, 훈련, 시즌, 결과, 드래프트·계약, 장기 기록 순으로 실제 제공 기능을 확인한다. 각 단계에서 조작, 반응, 반복 클릭, 화면 이동, 모바일 가독성을 기록한다. 은퇴와 회차는 실제 메뉴에 도달할 경우 별도로 확인한다.

사용자가 직접 플레이한 화면을 공유하면 출처를 사용자 제공 자료로 표시해 화면별로 분석할 수 있다. 해당 분석과 TF팀장의 직접 플레이 기록은 구분한다.
