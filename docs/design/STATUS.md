# 설계 현황 — 기준본1.0 + 빈티지 시각 확장1.4

2026-10-19. 사용자 선택은 세 번째 **빈티지 기록실**이다. 현재는 상세설계·정적 화면 시안 단계이며 실제 게임·DB·APK·배포 구현은 시작하지 않았다.

## 이번 진행

[98 구단 운영 상세](98-CLUB-OPERATIONS-IMPORT-EXPERIENCE.md)에 선수단·탐색·영입·예산·보관 투입5종/15상태와 예외·중단 후 재개를 추가했다.

- 선수단: 전체/1군·포수·타순 요건,포수 부족과 부상 대체 사례. 직접 교체/등록 확인 전 임의 방출이나 건강 복원 없음.
- 탐색: 발견63% 예시,비용500만원·월 기회2→1,성공3명/실패0명,기존 후보 유지. 발견과 영입은 별개.
- 영입: 단독1라운드 수락50%,1년/1억원 제안 예약,최신 재검사,소유·계약 확정과1군 등록 분리.
- 예산: 가용18억4천만원,탐색 후18억3500만원,제안 예약→연봉 예약의 보존. 치트 무제한 표기와 유한 금액 원장.
- 보관 투입: 새 구단 생성에서 원본41세의 능력별 최고→19세 반값/종합45.8,병역/기록 초기화,새P 고정. 치트 소유 시P100이며 현재A와 원본은 그대로.

[비교 보드](art-direction-lab.html)는 대표16화면·상세12흐름×3상태=36시안이다. 정상/오류/치트 등은 독립 비교 사례이며 모두 선형 진행이라는 뜻이 아니다. 원래45게임 화면/99이벤트는 유지한다. 새로운 게임 기능이나 진행 중 구단의 임의 원본 추가 기능을 만든 것은 아니다.

[구단 수치·예외](club-experience-examples.json)에20개 NOT_IMPLEMENTED 기대값을 추가했다. 기존 result-experience-examples.json의14개와 별도 카탈로그이며 기존298게임 fixture에 합산하지 않는다.

최신 사용자 폴더는 V:\docs\design(원래 네트워크 baseball_career\docs\design)이다. Git 작업용 로컬 checkout에서 수정하고 기존 파일 변경 충돌을 확인한 뒤 네트워크 폴더에 동기화·해시 검증한다. 기존 baseball-design 미리보기의HTML도 갱신한다. 삭제한 design-v0.7은 다시 만들지 않는다.

이미지 신규 생성은 없다. assets/art-lab의8PNG(메인3안/이전 사건 비교1/선택 아틀라스2·12패널/초상2)를 재사용한다. 선수단·예산은 데이터 우선,탐색·제안은 단장 책상,보관 원본은 회상 장면이다. 전체 캐릭터 프리셋과45개 최종 렌더 완성이 아니다.
