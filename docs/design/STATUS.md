## 검수와 제한

node docs/design/verify-design.mjs 통과. 새 검사: 초상2 PNG/alpha 메타데이터, 대표8종, 상세4흐름×3상태의 데이터와 순수 HTML 문자열, 상태별 그림, 능력 평균/집중 개수, 기존 링크·스크립트·45슬롯 정합. 기존298서면 게임 기대값은 NOT_IMPLEMENTED, 12실행 게이트는 NOT_EXECUTED를 유지했다.

출력 이미지를 도구에서 확인했다. 투수 초상1130×1392의 alpha 채널을 확인했다. 미세한 실루엣 색 테두리·실제 축소 가독성·합성 품질은 제작 검수 과제로 남긴다.

자동 브라우저는 file: URL 정책 차단 상태다. 서버나 다른 브라우저로 우회하지 않았다. 실제 픽셀 렌더·클릭·줄바꿈·키보드·클립보드·localStorage는 미검수다. 순수 문자열 검사를 실제 화면 시험으로 해석하지 않는다. 게임엔진/Neon/로그인/강제종료 복구/build/APK도 미실행이다.
