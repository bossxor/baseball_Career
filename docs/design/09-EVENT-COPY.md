## 후속 결과 템플릿

역할경쟁: 실제변경있음 "{newRole}에서 {appearances}경기를 맡았습니다. 요청했던 변화가 실전에 이어졌습니다." / 없음 "역할을 요청했지만 기용은 크게 달라지지 않았습니다. 다음 기회를 준비합니다."

육성: 실제증가>0 "집중했던 {ability}이 {delta} 올랐습니다. 실전 성적은 별도로 확인할 수 있습니다." / 0 "이번 시즌 {ability}의 표시 능력치는 변하지 않았습니다. 성장 상한과 누적 잔여치를 확인할 수 있습니다."

부상복귀: 실제출장>0 "복귀 뒤 {appearances}경기에 나섰습니다." / 0 "출전 가능 상태로 돌아왔지만 남은 일정에서 기회를 얻지 못했습니다."
