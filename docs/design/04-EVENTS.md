# 04. 이벤트 사양과 콘텐츠

이벤트는 참고 게임 문구를 복사하지 않은 독자 콘텐츠다. 표의 수치와 확률은 기본 설계값. '슬럼프' 같은 제목만 정하고 결과를 구현 중 임의 생성하는 것을 피하도록 조건·선택·효과·종결을 명시한다.

## 공통 이벤트 계약

EventDefinition: id, version, mode, phases, eligibility predicate, priority, weight, cooldownSeasons, maxPerCareer, title, bodyTemplate, choices[]. Choice: id, label, effectPreview, immediateEffects[], deferredEffects[], nextEventId?, terminalPhase?. Instance: instanceId, definitionVersion, saveId, season, playerId, contextSnapshot, offeredChoices, rngState, resolvedChoiceId, result, resolvedRevision.

변수는 이름/구단/포지션/시즌/성적에 한정하고 HTML 삽입 금지. 효과는 abilityDelta, fatigueDelta, focusOverride, roleRequest, contractDecision, moraleDelta, timelineEntry, retirement, pendingFollowUp. 정의에 없는 임의 스크립트 실행 금지. morale은 0~100, 기본50, 경기 보정은 (morale-50)×0.001로 ±5% 제한.

우선순위: 은퇴/계약 만료100 → 부상90 → 로스터/콜업80 → 경력전환70 → 육성60 → 관계/서사20. 동시에 하나만 노출. 강제 사건은 모두 순서대로 처리하고 일반 사건은 체크포인트마다 최대1개, 시즌 최대3개. 일반 사건 없는 체크포인트도 허용한다. 일반 추첨확률35%, 조건 충족 후보의 weight는 기본1. 추첨은 저장된 seed로 한 번, 새로고침 시 재추첨 금지.

기본 쿨다운2시즌, maxPerCareer=2. 고유 사건은1회. 조건 이탈한 대기 이벤트는 무효화하고 아무 효과도 적용하지 않은 사유를 남긴다. 이미 부상한 선수에게 새 부상을 중첩하지 않는다. 기본 선택을 자동 확정하지 않는다. 후속 사건은 다음 검증 시점에 조건을 다시 확인하고 실제 결과를 서술한다.

## 수상과 기록 사건

첫 출전/첫 안타/첫 홈런/첫 승/첫 세이브, 1000안타/200홈런/100승/200세이브, MVP·신인상·포지션상·우승은 자동 타임라인 사건이다. 선택 이벤트 예산을 소비하지 않고 중복키(playerId,milestoneId)로1회. 미달한 기록을 반올림해 달성으로 표시하지 않는다. 정규/PS 누적을 섞지 않는다.

## 편집·검증 게이트

모든 선택에서 다음 상태가 존재해야 한다. 실제 조건으로 표시 가능한 변수만 사용한다. 만료 임시효과는 동일 effectId로 한 번 제거하며 영구 능력치에서 빼지 않는다. 은퇴/계약/부상과 일반 사건 충돌을 테스트한다. E01~E40 본문·선택 결과 초안은09에 작성했다. 조건별 변수와 화면 검수까지 마쳐야 최종 콘텐츠 완료다.
